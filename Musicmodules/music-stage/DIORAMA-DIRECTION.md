## 施工修订与视觉审核交接（2026-09-23）

本节优先于下文原始提案中的冲突描述；原始提案保留为设计愿景，不代表全部功能已经实现。

### 站牌演出修订

- 取消“每个乐句一块实体站牌”和 LED 点阵方案。多句清晰文字共用同一块实体牌，文字页面作为牌体子节点，使用牌面局部坐标。
- 按行驶距离、车速倍率、视口比例和阅读视锥预算分组，一次经过承载多句歌词，优先在句间留白交接。
- 牌体固定于轨道左右两侧交错出现；相机继续前进，并在接近时转向牌面、阅读后回到前路。当前实现不为每块牌单独修改车速。
- 实体牌框、支柱与歌词页面独立管理。换句不更换牌体；牌体在远雾中提前加载，在车后远处回收。
- 当前采用有上下限的阅读距离预算，不保证任意歌词输入下的站间距绝对恒定；极长连唱、密集快句仍需录屏审核。
- 世界站台、接触网等设施与歌词屏不是同一个生命周期；设施开关不会关闭歌词。

### 无站牌演出修订

- 取消与字形脱节的独立粒子。使用共享文字纹理和逐字四边形，在同一几何上执行揭示、起落、纵深展开和退场。
- 牌上文字仅在牌面内小幅强调；无牌文字具有更明显的深度动作，演唱时保持可读。所有动作由绝对播放时间求值，减少动态效果时禁用。
- 已实现站牌与星空两类主要载体；完整独立灯箱、水面文字载体尚未实现。
- 星空载体提供反射专用翻译层，关闭水面反射时回到普通字幕。倒影方向、位置、双语可读性仍需视觉审核。

### 时间与音乐契约修订

- 共享实时频谱通量检测用于光照、材质响应，不决定相机位置或站牌位置。
- 有明确拍点时使用拍点；无拍点时使用标明来源的“行驶节律”，不把歌词间隔推断成真实强拍。
- 铁轨沿水平曲线按距离采样；相机由绝对播放时间直接求值，不依赖逐帧积分或输出阻尼。
- 合法剪辑避开人声保护区；站牌阅读期间的注视由经过编排接管。
- 电线杆目前按固定空间间隔和章节密度摆放，不宣称每根杆严格对齐音乐强拍。

### 已接入的实现

- 导演章节、重复歌词候选、前奏/间奏/尾声、纯音乐行程。
- 水平轨道、贴轨/前向/侧窗/开阔机位、平滑时间噪声、阅读稳定；增加乐句级横向伴随、缓升、轻推、焦段变化，动作在乐句边界收束。
- 天空银河、天球星点、月光、地平线剪影、全局镜面水面。
- 实例化铁轨、枕木、电线杆、下垂接触网；沿线恢复有顶候车月台、递进门廊、临水阶梯和残缺窗廊四类建筑组合，包含长椅、支柱、灯带与缺失变化。
- 左右交错的多页实体站牌、共享纹理逐字几何编舞、翻译与罗马音。
- ACES 色调映射、轻量高光扩散、横向光晕、暗角、胶片颗粒、电影遮幅。
- 三档画质、浅色主题、暂停冻结、回拖同位、DOM 文字降级和资源释放。

### 验证与限制

- 8 项导演/音频/站牌编排/镜头连续性测试及 8 项现有舞台测试通过。
- 浏览器测试覆盖开场、建筑实例、左右交错、牌面父子关系，以及 135 个演唱时刻按实际顶点动画计算的阅读边界和牌面范围；另覆盖窄屏三档画质、浅色、反射关闭、运动关闭、纯音乐、暂停及销毁。
- 当前样例章节含反射与后期的总绘制次数为 33～50；这不是全部歌曲或全部设备的性能保证。
- 投影与牌面范围测试不等于遮挡检测，也不证明画面自然、丰富或令人舒适。新增建筑对歌词的实际遮挡和连续镜头观感仍需审核。
- 暂停图像比较允许极少量单色阶量化差异；相机回拖位置仍使用精确比较。
- 尚未证明原提案的“所有文字屏高至少 6%”、集显帧时间目标、任意重叠人声完整显示或连续三分钟无眩晕。
- 固定地面长焦、完整回望机位、桥洞遮挡转场、甩镜拖影和专门停站减速尚未实现。
- 审核材料：浏览器测试生成章节截图、浅色/反射关闭/运动关闭/纯音乐截图及 JSON 调试报告，均位于 artifacts/diorama 目录。
- 视觉审核重点：四类建筑是否真正形成纵深与叙事变化、站间疏密与经过感、牌体加载是否可察觉、牌面换句与字号、无牌字片展开及倒影、乐句运镜和左右转向舒适度。

> 代号：**末班车 / Last Train to the Stars**
> 一句话：一列看不见的夜行列车，沿着铺在浅水平原上的铁轨驶向星空。歌词是沿途的站牌、车窗外掠过的灯箱、以及落在水面上的光。

本文档是镜台模式的最高层设计约束。后续所有实现（镜头、场景、歌词、音频映射）都要能回答一个问题：**"这在那列火车上看得到吗？"** 看不到的东西，不进画面。

## 0. 诊断：为什么现在"粗糙、不连续、不卖力"

| 问题 | 现状 | 根因 |
|---|---|---|
| 世界不连续 | 每 4 行切换一种站点（helix → platform → memory → water → echo 循环） | 站点序列与歌曲结构无关，本质是按行号轮播的幻灯片 |
| 视觉语言打架 | 液体球 + 线框符号 + 双螺旋光轨 + 2D HUD 角标 + 星尘隧道 + 站台，同屏 5~6 套语言 | 每次迭代"加一层"，没有删减；没有统一世界观 |
| 不像铁道片 | 镜头在飞，不在"行驶" | 路径含 ±0.22 rad 俯仰，是无人机轨迹；铁轨、站台、水面在起伏路径上无法成立 |
| 手持感假 | `sway/bob` 是 `interLineProgress` 的正弦函数 | 每行重复同一条曲线，节奏跟随"歌词行"而非时间，所以机械；幅度又被压到几乎为 0，所以平淡 |
| 只有一个镜头 | 永远是"正后方跟拍 + 指数阻尼" | 没有景别、焦段、朝向、高度变化，也没有剪辑点 |
| 歌词是广告牌 | 悬在路径正中的平面，唱完后整体被拽向镜头后方并淡出 | 歌词不属于世界；必须挡在镜头正前方，离场只能"硬拽" |
| 音乐映射碎 | bass → 粒子透明度 / 液体膨胀；vocal → 辉光 | 全是连续数值抖动，没有"段落 / 乐句 / 拍"的结构映射，副歌与主歌看起来一样 |
| 无光 | 全部 `MeshBasicMaterial` + 加法混合 + 线性雾 | 没有主光、色温、明暗层次，奢华感无从谈起 |

**结论**：不是参数没调好，是缺少"导演层"。需要：一个统一的世界 + 一条连续的轨道 + 一个理解歌曲结构的导演 + 一套镜头语法 + 让歌词成为世界里的物体。

## 1. 世界观与空间结构

### 1.1 唯一的世界
整首歌只有**一个连续空间**：无边际的浅水平原（镜面），一条铁轨贴水面延伸到地平线，头顶是星空与银河。

- **水不再是"站点"，而是整首歌的地面**（世界坐标 `y = 0`，无限平面，跟随相机平移）。它是星空的镜子，也是歌词落下的地方。
- 站台、电线杆、信号机、灯箱都是**沿铁轨出现的物体**，密度随段落变化，而不是整体切换场景。
- 远景（地平线、星空、月亮、远方城市灯带）**永远不动或极慢**——这是连续性的锚。只要远景不跳，近景怎么变观众都认为是"同一趟旅程"。

### 1.2 三层纵深（速度感与宏大感的来源）
| 层 | 内容 | 视差 | 职责 |
|---|---|---|---|
| 近景 | 枕木、钢轨反光、偶尔的车窗框 / 雨痕、掠过的电线杆 | 极快 | 速度感、镜头的"物理存在感" |
| 中景 | 站台、站牌 / 灯箱（歌词载体）、信号灯、水面涟漪 | 中 | 叙事与阅读 |
| 远景 | 地平线剪影、城市光带、月亮、银河、星空倒影 | ≈ 0 | 氛围、连续性、奢华 |

### 1.3 色彩与光
三色原则，全部映射自主题色（`stagePalette`）：
- **夜色**（`background`）：天空、水、雾，占画面约 70%。
- **钠灯暖**（`accent`）：站台灯、当前演唱字、信号"通过"。
- **信号冷**（`secondary`）：月光、星河、已唱文字的冷却色、水面高光。

光源：1 个冷色月光（方向光，定义明暗）+ 少量暖色点光（站台钠灯，同时最多 2~3 盏）+ 天空渐变 shader。雾改为 `FogExp2`，颜色 = 地平线颜色，使远处物体"溶进天际"而不是"变黑"。
浅色主题：同一套结构改为"黎明 / 白夜"——天空高亮、水面雾白、钠灯改为墨色剪影，不另做场景。

## 2. 导演层：章节化演出（Acts）

### 2.1 段落分析（纯函数，可测试）
输入：`lines[]`（含 `startTime / endTime / isChorus / fullText`）。输出：`acts[]`。
1. `isChorus` 标记优先（运行时已提供）。
2. 无标记时：重复度检测——`fullText` 归一化（去标点、空白、大小写）后，出现 ≥ 2 次的连续行组视为副歌候选；取重复次数最多、总时长最长的组。
3. 行间隙 > 6 s 视为间奏；首行之前为前奏；末行之后为尾声。
4. 副歌前 1~2 行标为预副歌（Pre）。
5. 全部失败时退化为：前 25% 主歌、每隔 8 行一次"开阔段"，保证任何歌都有起伏。

### 2.2 Act 定义
| Act | 画面 | 速度 | 主镜头 | 世界密度 | 歌词载体 |
|---|---|---|---|---|---|
| **Departure** 前奏 | 黑场中远处一盏信号灯亮起，铁轨从暗中浮现 | 0 → 慢 | RAIL 贴轨低角 | 极稀 | 无 / 曲名站牌 |
| **Verse** 主歌 | 夜行、侧窗、零星站台与电线杆 | 中 | WINDOW 侧拍 / CAB | 中 | 站牌 / 灯箱 |
| **Pre** 预副歌 | 电线杆加密、灯光变暖、信号灯红→绿 | 加速 | 从侧向逐渐转向正前 | 高 | 站牌（更近更大） |
| **Chorus** 副歌 | 站台消失，开阔水原，星河倒影全开 | 快但平稳 | WIDE 高广角 | 极稀（只剩星空与水） | 星座：悬于水面上空，倒影同步 |
| **Interlude** 间奏 | 经过一座无人站台停靠，或穿过桥洞 | 减速至近停 | HOLD 长焦 / REVERSE 回望 | 单一地标 | 月台广播式小字（可选） |
| **Terminus** 尾声 | 列车减速，镜头上摇至星空 | → 0 | 上摇 | 无 | 最后一句留在水面倒影里 |

### 2.3 参数包与连续性
每个 Act 是一个参数包：
```
{ speed, fov, rig, height, lateral, yawBias, handheld,
  poleDensity, platformChance, lightWarmth, starIntensity,
  waterRoughness, lyricCarrier, fogDensity, letterbox }
```
Act 之间在 **2~4 秒** 内插值（参数连续，对象不销毁不切换）。这是"统一"与"连续"的机制保证：画面上永远只有一个世界在缓慢改变状态，而不是场景 A 淡出、场景 B 淡入。
第二次出现的副歌复用第一次的参数包，但 `starIntensity`、`speed` 上调约 15%——**重复但升级**，这是故事感的最小单位。

## 3. 镜头语言

### 3.1 运动基础：弧长驱动，而不是"每行一个点"
- 轨道是一条**水平**样条（只允许 yaw 缓弯；pitch 恒为 0；弯道处轻微 bank ≤ 3°）。
- 预计算弧长-时间表 `s(t) = ∫ speed(Act(t)) dt`（加减速在 Act 插值中自然产生）。
- 列车位置 `train(t) = track.at(s(t))`；相机 = `train(t)` ⊕ 当前机位 rig 的局部偏移 ⊕ 手持噪声。
- **所有量都是 `playbackTime` 的纯函数**（除输出端一层轻阻尼）。暂停即冻结，拖动进度即精确落位，与现有冒烟测试的"暂停冻结 / 回拖同位 / 间奏前进"断言兼容。

### 3.2 机位库（Rigs）
| Rig | 高度 | FOV | 朝向 | 用途 |
|---|---|---|---|---|
| RAIL | 0.5 | 36° | 正前方，贴近钢轨 | 前奏、速度感、铁轨消失点构图 |
| CAB | 2.2 | 48° | 正前方，略偏左（司机位） | 主歌默认，前路预瞄下一块站牌 |
| WINDOW | 1.8 | 44° | 偏航 60~85°（侧窗） | 主歌叙事，灯箱与电线杆横向掠过，视差最强 |
| WIDE | 6~9 | 58° | 前方偏下 8°，缓慢升降 | 副歌，星河与倒影，开阔 |
| HOLD | 3 | 22° | 固定于地面，列车驶过 | 间奏，长焦压缩，"旁观"感 |
| REVERSE | 2.0 | 40° | 回望 | 间奏 / 尾声，唱过的歌词在远处退去 |

每个 rig 定义一个**阅读槽（Reading Slot）**：画面中留给当前歌词的屏幕区域（例如 WINDOW 为画面中心偏上 60% 宽度）。歌词摆放由阅读槽反推，保证可读性是"构造出来的"，而不是"调出来的"。

### 3.3 手持感模型（有呼吸，但不晕）
替换现有 `sin(interLineProgress)`：
- 噪声源：2~3 个八度的平滑值噪声，**以真实播放时间为输入**，每个 rig 独立种子。
- 位置噪声：≤ 2.5 cm（RAIL/CAB）、≤ 6 cm（WINDOW）、≤ 1 cm（HOLD，三脚架）。
- 旋转噪声：yaw/pitch ≤ 0.35°，roll ≤ 0.25°（旋转比平移更决定"手持感"，也更容易晕，所以严格上限）。
- 摄影师呼吸：0.18~0.25 Hz 的极缓垂直起伏，幅度 1 cm。
- 铁轨接缝：每经过一个接缝（与拍对齐，见 §5.3）给一次阻尼弹簧冲击，≤ 1.5 cm、衰减 0.25 s——"哐当"感来自这里。
- **阅读稳定**：有字正在演唱时，旋转噪声 × 0.5；句间与间奏放开到 × 1.0。镜头"呼吸"发生在留白处。
- 全部幅度乘以 `motionAmount × animationIntensity`；`prefers-reduced-motion` 时噪声为 0、禁用剪辑，只保留匀速行驶。

### 3.4 剪辑（Cuts）
- 允许剪辑的时刻：Act 边界；或行间隙 ≥ 1.2 s 的行边界。永远不在一个字正在演唱时剪辑。
- 频率上限：8 s 内最多一次；副歌内原则上不剪（用一个连续 WIDE 升降长镜头承载情绪）。
- 剪辑点对齐到最近的强拍（若可估计），否则对齐下一行 `startTime - 0.15 s`。
- 转场手法（全部是"世界内"的遮挡，而非叠化）：
  - **硬切**：主歌内机位切换。
  - **桥洞黑场**：列车穿过一段桥洞 / 隧道 0.3 s，暗场掩护换机位——Verse → Interlude。
  - **甩镜**：WINDOW 快速横摇转正前（0.4 s，带方向拖影）——Pre → Chorus 的"起飞"。
  - **上摇**：CAB 缓慢上仰至星空——Terminus。
- 剪辑表 `cuts[]` 与 `acts[]` 一起在切歌时预计算，确定性、可测试。

## 4. 歌词演出

### 4.1 原则
1. 歌词是**世界里的物体**，被列车经过，而不是贴在镜头前的字幕。
2. 离场靠"经过"（相机驶过它，视差自然带走），不再把整组歌词向镜头后方硬拽。
3. 未来的歌词**在远处已经可见**（下一块站牌在地平线附近亮着微光）——这是"前路感"，也是铁道片的迷茫：你知道前面有东西，但还看不清。

### 4.2 摆放
歌词锚点 = `cameraPose(line.startTime + lead)` 在当前 rig 阅读槽方向上的投影点，`lead ≈ 0.6 s`。即：先算"唱这句时镜头在哪、看向哪"，再把字放到镜头会看到的位置。推论：
- CAB：站牌立在铁轨右侧前方，随列车接近而放大。
- WINDOW：灯箱在车窗侧面平行排布，横向滑过画面，演唱进度与滑过速度一致。
- WIDE：星座字悬于水面上空，倒影在水里同步点亮。
- 场景道具生成时避开"歌词占位体积"，从根本上消除遮挡。

### 4.3 载体（Carriers）
| 载体 | 形态 | 逐字激活 | 已唱 | Act |
|---|---|---|---|---|
| 站牌 | 珐琅双色牌，上方小字站序号（行号），下方翻译 | 字"亮起"：一次荧光灯管式轻闪（~80 ms）后稳定，站台钠灯同步增亮 | 冷却为 `secondary` 冷色，保持可见直到被经过 | Verse / Pre |
| 灯箱 | 背光半透明面板，随窗外掠过 | 背光从左向右扫亮 | 背光熄灭，只剩轮廓 | Verse（WINDOW） |
| 星座 | 字由星点连线构成，悬于水面上空，水中倒影同步 | 星点依次点燃，连线从上一字"生长"到当前字 | 保留为星图，逐渐并入银河背景 | Chorus |
| 水面字 | 贴近水面的浅色字，随涟漪轻微扭曲 | 字下方荡开一圈涟漪 | 被涟漪抹平 | Interlude / Terminus |

- **同一首歌同一种载体内风格恒定**；载体切换只发生在 Act 边界，并随 Act 插值交叉过渡（旧载体继续存在直到被经过，新载体从远处出现）。
- 字体：保留 144 px 光栅化，但站牌用粗黑体、星座用细体、水面字用宋 / 明朝体风格回退链。字形差异本身就是"章节感"。

### 4.4 逐字激活节奏
- 等待：可读但压暗（opacity 0.38，冷色），不能是"看不见"——阅读永远先于演出。
- 激活：80 ms 起亮 + 轻微 1.04 倍放大 + 辉光峰值，然后 250 ms 内回落到稳定亮度。**不做持续脉动**（持续脉动 = 廉价感的主要来源）。
- 已唱：保持 0.85 亮度，色温从 `accent` 在 0.6 s 内冷却至 `accent` 与 `secondary` 的中间色。
- 长音（单字时长 > 0.8 s）：辉光随 `vocal` 包络缓慢呼吸，是唯一允许的"持续动画"。

### 4.5 翻译 / 罗马音
- 站牌：翻译作为站牌下沿的副标题，与主文字同一物体（不再是独立浮板）。
- 星座 / 水面字：翻译只出现在倒影中——"水里的是另一种语言"。这是整个模式最重要的一个诗意细节，成本很低。

### 4.6 离场
- 歌词不主动移动。离场 = 相机驶过它。
- 若镜头朝向导致驶过前字就出画（如 WINDOW 侧拍），则在出画后 1 s 内淡出释放资源。
- 回退 / 拖动进度：因为摆放是 `lineIndex` 与时间表的纯函数，重建即可精确复位。

## 5. 音乐映射（结构优先，数值其次）

音乐映射分三层，**高层决定"演什么"，低层只负责"抖一下"**。低层幅度永远被高层包络限制。

### 5.1 段落层（秒 ~ 分钟）——决定 Act
来自 §2 的 `acts[]`。决定速度、机位、世界密度、色温。这是观众感知"副歌来了"的主要来源，**不是**低频能量。

### 5.2 乐句层（行）——决定镜头与载体
- 行开始：阅读稳定开启、下一块载体开始从远处接近。
- 行间隙：手持放开、允许剪辑、电线杆 / 灯光序列加密。
- 行长度 → 载体尺寸：长句用更宽的灯箱或双行站牌，避免缩小字号。

### 5.3 节拍层（亚秒）——铁轨接缝
- 若运行时能提供 onset / beat：每个强拍 = 一次铁轨接缝冲击（§3.3）+ 电线杆掠过。**"哐当—哐当"与鼓点同步**是铁道片音乐感的核心。
- 若无节拍信息：用 `bass` 包络的上升沿检测（阈值 + 最小间隔 0.28 s）近似；再无则按固定 0.9 s 周期，保证行驶感存在。
- 电线杆摆放在弧长上，其间距 = `speed × 拍间隔`，所以杆子掠过的节奏自然等于音乐节奏。

### 5.4 连续层（帧）——只做点缀
| 信号 | 映射 | 上限 |
|---|---|---|
| bass | 钠灯亮度微涨、水面涟漪振幅 | ±12% |
| mid | 星空闪烁频率 | ±20% |
| treble | 钢轨高光的细碎闪烁 | ±15% |
| vocal | 当前字辉光（仅长音呼吸） | ±25% |

全部经过已有的"快起慢落"包络（attack 16 / release 5），暂停时冻结。**禁止**把任何音频量直接映射到相机位置——镜头只听段落层与节拍层。

## 6. 场景构成：删什么、留什么、加什么

### 6.1 删除（与世界观冲突）
| 元素 | 处理 | 理由 |
|---|---|---|
| 液体流变体 `createLiquidBlobs` | 删除 | 火车上看不到水银球；它是整个画面"突兀感"的第一来源 |
| 线框符号 `createFloatingGeometry` | 删除 | 十字 / 三角 / 方框是 UI 语言，不是世界语言 |
| 双螺旋光轨 `createFlowingRibbons` | 删除 | 与铁轨争夺"路径"语义，而且贯穿全曲，无法做章节变化 |
| 站点 `helix` 类型 | 删除 | 同上 |
| 2D HUD 角标 `createVectorDecor` | 改为可选的**电影遮幅**（2.39:1 黑边，副歌时收起） | 取景框应该是镜头的，不是游戏 UI 的 |
| 星尘隧道 `createCorridorParticles` | 改造为**天球星空 + 水面倒影** | 星星在天上，不在隧道壁上 |

### 6.2 保留并重构
- **水面反射**（`diorama-stations.js` 的镜面相机与斜裁剪实现是对的）：从"站点"提升为全局地面，只保留一个实例。
- **站台 / 长椅 / 门框 / 缺失座位的变体**：这是现有代码里最有故事感的部分——"下一次经过时少了一张椅子"。保留这个"重复中的缺失"母题，扩展到站牌（站名逐渐褪色）、灯（某盏灯熄灭）。
- **窗框母题（memory / echo）**：改为 WINDOW 机位下的**车窗框前景**，而不是飘在空中的框。

### 6.3 新增
| 元素 | 实现要点 | 成本 |
|---|---|---|
| 天空 | 大球体 + 渐变 shader（天顶 `background` → 地平线提亮 → 银河带噪声），`depthWrite:false`、最先渲染 | 低 |
| 星空 | 单个 `Points`，天球坐标固定，大小按星等分布，闪烁由 `mid` 调制 | 低 |
| 铁轨 | 两根钢轨（细长 box，高光材质）+ 枕木 `InstancedMesh`，沿弧长生成、以相机为中心滚动复用 | 低 |
| 电线杆 / 接触网 | `InstancedMesh`，间距 = `speed × 拍间隔`，线用下垂悬链线 | 低 |
| 地平线剪影 | 远处低矮山脊 / 城市灯带，一张环形条带贴图（程序生成） | 低 |
| 月亮 | 带光晕的 sprite，位置固定，同时是方向光的方向 | 低 |
| 站台灯 | 每座站台 1 盏 `PointLight`（全局最多 3 盏，距离排序复用） | 中 |

### 6.4 已知 bug：水面遮挡站台（根因与修复）
**根因有三个，叠加出现：**
1. **路径有俯仰**：`buildDioramaPath` 每步 pitch 最大 ±0.22 rad，11.5 单位步长下相邻帧高差可达 2.5 单位。水面按"站点第一帧"的基向量摆成一整块平面，而站台块按各自帧 `frameGroup(start + j)` 摆放——后续帧的站台会**沉到水面以下**或悬在水面上方，于是水面"切"进站台。
2. **透明排序**：水面与站台材质均为 `transparent:true, depthWrite:false`。three.js 按物体中心距离排序透明物体；水面是一整块 28×64 平面，中心在站点中段，经常比远处站台更近，于是**后绘制并覆盖**远处站台。`renderOrder = 2` 对不同 `renderOrder` 组才生效，站台默认 0 → 水面总是画在站台之后。
3. **镜面相机近裁剪**：水面平面随站点倾斜后，镜面平面与真实地面不一致，反射图里的站台倒影位置也会错位，加重"穿插"观感。

**修复方案（随新架构一起落地，不做补丁式修复）：**
- 轨道 pitch 恒为 0，水面 = 世界 `y = 0` 的唯一平面，所有道具的"地面高度"是常数。
- 水面 `renderOrder` 最低（紧随天空），且**写入深度**（`depthWrite:true`，alpha 由 fresnel 控制但不透明度 ≥ 0.85）；站台、铁轨、电线杆改为**不透明**材质并写深度。透明物体只剩歌词与辉光，排序问题从源头消失。
- 反射渲染时隐藏歌词的"倒影专用层"之外的辉光层，避免辉光在倒影里重复叠加过曝。

## 7. 实现架构

### 7.1 模块划分
```
modes/
  diorama-manager.js     // 壳：生命周期、Three 初始化、渲染循环、资源释放、降级（保留）
  diorama-director.js    // 纯函数：lines → { acts, cuts, beatGrid, timeline }（新，可在 Node 单测）
  diorama-camera.js      // 纯函数：(timeline, t, tuning) → { position, quaternion, fov }（新）
  diorama-world.js       // 天空、星空、水面、铁轨、电线杆、地平线、站台（替换 stations）
  diorama-lyrics.js      // 载体：站牌 / 灯箱 / 星座 / 水面字；摆放与逐字激活（从 manager 拆出）
```

### 7.2 数据流（每帧）
```
frame.playbackTime ─┐
                    ├─► director.sample(t)  → { act, actBlend, rig, rigBlend, beatPhase, reading }
timeline (预计算) ───┘            │
                                 ├─► camera.pose(t)   → 相机（纯函数）→ 输出端 1 层轻阻尼
                                 ├─► world.update(s(t), act 参数, audio 包络)
                                 └─► lyrics.update(t, 当前 rig 阅读槽, wordStates)
renderer: 天空 → 水面(先渲染反射) → 不透明世界 → 歌词 → 辉光
```

### 7.3 确定性约束（沿用并强化现有测试契约）
- 除输出端阻尼外，所有状态都是 `playbackTime` 的纯函数；阻尼只在 `isPlaying && clockDelta ≠ 0` 时推进。
- 跳转（|Δt| > 0.75 s 或回退）直接落位到目标，不阻尼。
- `acts / cuts / beatGrid / 摆放种子` 只依赖 `trackId + lines`，切歌时整体重建。
- 以上保证现有冒烟测试中的"暂停冻结、回拖同位、间奏前进、关闭站点后无残留、销毁后无 canvas"断言继续成立。

### 7.4 配置项映射（兼容现有 `modes.diorama`）
| 现有键 | 新语义 | 说明 |
|---|---|---|
| `narrativeStations` | 站台 / 电线杆 / 灯箱等沿线道具开关 | 关闭后仍保留天空、水面、铁轨（世界不消失） |
| `stationIntensity` | 沿线道具密度倍率 | 0 = 空旷水原 |
| `waterReflection` / `waterStrength` | 全局水面反射开关 / 强度 | 关闭时水面退化为无反射的渐变镜面 |
| `cameraSpeed` | 弧长速度倍率（作用于 `s(t)`） | 不再影响阻尼系数 |
| `motionAmount` | 手持噪声 + 剪辑幅度倍率 | 0 = 纯匀速行驶、无剪辑 |
| `audioReactivity` | §5.4 连续层倍率 | 不影响段落层与节拍层 |
| `showParticles` | 星空开关 | |
| `geometryMode` | `clouds` → 重定义为"电影遮幅"；`corridor` → 无遮幅 | 保留枚举值以免破坏已存配置 |
| `glow` | 歌词辉光强度 | |

新增（可选，后续加入 `music-stage-config.js` 与 host 面板）：`cameraCuts`（自动剪辑开关）、`letterbox`（遮幅）、`lyricCarrier`（`auto` / `sign` / `constellation`，强制单一载体）。

| 辉光 | 纹理辉光 | 纹理辉光 | 纹理辉光 + 轻量 bloom（可选） |

## 10. 验收标准
**客观（进入冒烟测试 `tests/diorama-stations-smoke.cjs` 或新增 `tests/diorama-director.test.js`）**
- 暂停冻结、回拖同位、间奏前进、关闭道具后无残留、销毁后 canvas 数为 0（沿用）。
- `director` 对同一输入输出完全一致；含 `isChorus` 的歌词必产出 Chorus act；无标记歌词至少产出 2 种 act。
- 任一演唱中的字时刻不发生剪辑；任意 8 s 窗口内剪辑 ≤ 1 次。
- 当前演唱行的包围盒 100% 位于视口内，且屏幕高度 ≥ 视口高度的 6%。
- 水面（y=0）以上的道具不被水面像素覆盖（截图对比：站台区域亮度不因水面可见而下降）。
- 标准档 1280×800 下平均帧时间 ≤ 8 ms（集显 ≤ 16 ms）。

**主观（截图 / 录屏评审）**
- 任一截图单独拿出来，能看出是"夜行列车 / 星空 / 水面"的同一个世界。
- 主歌与副歌截图并排，无需歌词就能分辨。
- 连续观看 3 分钟不晕；关掉声音看，仍能感到"哐当"的行驶节奏。
- 同屏视觉语言 ≤ 3 种（光、线、字），没有"为了好看而加"的元素。
