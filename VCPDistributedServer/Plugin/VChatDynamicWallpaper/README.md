# VChat Dynamic Wallpaper

VChat 主聊天窗口动态壁纸插件，与 VCPDesktop 壁纸系统相互独立。

## 功能

- Agent 名称右侧提供紧凑的胶片控制栏。
- 左键展开或收起控制栏，右键选择视频文件夹。
- 支持上一个、播放/暂停、下一个、顺序播放、随机播放、单曲循环、静音和音量调节。
- 支持 `mp4`、`webm`、`mov`、`mkv`、`avi` 格式，按名称播放所选文件夹顶层的视频。
- 隐藏动态壁纸时显示当前主题壁纸；再次显示后恢复原播放状态。
- 自动保存所选目录、当前视频、播放进度和播放状态。
- 可通过“全局设置 → 快捷操作 → 启用动态壁纸”控制整体显示。
- 可在插件管理器中启用或禁用。manifest 变为 `plugin-manifest.json.block` 后，下次启动不会加载该插件的 CSS/JS。
