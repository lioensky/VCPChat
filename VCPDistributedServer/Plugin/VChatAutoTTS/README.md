# VChat Auto TTS

VChat 主聊天窗口自动朗读插件。

## 功能

* 在 Agent 的“语音设置 (Sovits TTS)”区域提供“自动朗读”和“朗读代码块”开关。
* 开关状态按 Agent 独立保存，切换 Agent 时自动同步。
* 自动朗读新完成的助手回复，不朗读启动或切换话题时载入的历史消息。
* 沿用 Agent 已配置的音色、语速和主副音色正则。
* 可在插件管理器中启用或禁用。manifest 变为 `plugin-manifest.json.block` 后，下次启动不会加载该插件的 CSS/JS。
