Chrome 系统字体原生匹配测试

本页不使用 @font-face、不读取字体文件、不使用 URL，只通过 CSS font-family 请求 Windows 已安装字体。上半部分测试新生成的规范化 family，下半部分保留 原字体的中文、英文和 PostScript 名作为对照。请先安装 font-compat-output 中的 7 个兼容副本，并完全退出、重新启动 Chrome；若外观与“必定不存在字体” 一致，说明 Chrome 已静默回退。
