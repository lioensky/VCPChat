# 桌宠交互与资源检查（2026-10-23）

本轮检查覆盖桌宠宿主、页面编排、Live2D/网格/精灵后端、会话状态、素材协议及窗口生命周期。内置形象为 Nova 女仆、Nova Q 版和 Codex 刻晴。

## 控件行为

| 情况 | 第三个按钮 | 上方会话状态卡片 |
| --- | --- | --- |
| 没有运行任务或未读动态 | 隐藏，连同分隔线一起收起 | 隐藏 |
| 正在运行，或结束后尚未查看 | 铃铛，显示会话数量 | 收起 |
| 用户点击展开 | 向上箭头 | 展示所选会话标题和当前状态 |
| 查看完全部已结束动态，再收起 | 隐藏，恢复两个按钮 | 隐藏 |

正文回复、错误提示、语音和工具审批有各自的交互，不通过铃铛取消。审批优先使用头顶空间。新活动不强行展开卡片。

拖动时主进程保留指针接收，忽略迟到的透明像素结果；起点使用窗口内 DIP 坐标，避免多屏缩放下的全局坐标差异。丢失指针捕获、取消、失焦和页面销毁都会结束拖动。原有按 Alt 松手取消贴边和抛掷的方式保留。

## 模块边界

| 层 | 责任 | 边界 |
| --- | --- | --- |
| `modules/ipc/deskPetHandlers.js` | 窗口、主聊天桥接、已验证的桌宠 IPC | 不包含模型绘制或美术绑定；聊天钩子用异常隔离保护主聊天 |
| `modules/deskpet/` | 素材、配置、会话归属、串行预览、几何和后台策略 | 不依赖页面 DOM；状态与聊天记录分别存储 |
| `DeskPetmodules/deskpet.js` | 页面编排、对话和各控制器连接 | 通过后端接口操作形象；不自行绑定或改写 Live2D 模型 |
| `pointerGestures.js` / `sessionCard.js` | 指针生命周期 / 会话展示与未读状态 | 提供显式释放接口，不直接移动原生窗口或读聊天文件 |
| 各形象后端 | 绘制、轮廓、命中、动画及暂停 | Live2D 与网格使用 Pixi；精灵仅使用 Canvas2D；隐藏停止绘制，销毁释放所持资源 |

本轮拆出了指针控制器。两个编排文件仍较长，后续扩展应继续抽取独立控制器，不再把新模型专用逻辑堆入它们。

## 已处理的资源与读取问题

- Pixi 和其 CSP 兼容脚本改为需要 WebGL 的后端按需加载；精灵与头像页面不加载 Pixi/Core。主进程图像元数据工具也改为首次用到时加载。
- 移除页面中已经不可见的旧工具卡片解析路径。会话清单只在开始、状态变化、标题变化和结束时随流发送，普通增量不重复携带完整清单。
- 工具结果长时间缺少结束标记时，保留头部与结束标记尾部，缓冲保持有界；仅有结果的活动列表也限制为最近 20 条。完成后释放解析缓冲。
- 会话页面销毁时取消订阅并清空解析器；删除助手、关闭模块时移除会话缓存。迟到的标题查询不能发布已删除会话。
- 初始化或挂载失败时销毁已创建的 Pixi 舞台；正常换装或页面退出时，显式清理绘制实例、纹理源、音频、测量计时器、窗口 resize 钩子和上下文丢失重载计时器。兼容引擎使用的 `baseTexture` 与 Pixi 8 的 `textureSource` 释放选项。
- 精灵命中掩码只保留 alpha 通道，v1 为 2,875,392 字节；不再长期保留 4 通道 RGBA 掩码。轮廓测完即释放临时整张图集画布，销毁时清空掩码和图像源。
- 关闭宿主时取消显示器/唤醒/主窗口监听、延迟恢复、等待主窗口应答和后台任务。
- 保持页面 CSP 对外部网络和任意脚本的限制。素材协议除路径段白名单外，实际读取前验证真实路径，阻止素材内的符号链接/Windows 目录联接越界读取配置或聊天记录；不将这些数据作为模型资源提供。

## 验证与测量

- 274 项桌宠相关自动测试通过，覆盖四方向拖动、多屏坐标、迟到命中、丢失捕获、状态联动、关闭清理、缓冲上限和链接越界。
- 真实 Electron/Core 窗口 26 项交互检查通过，控制台无错误；检查连续换装、两个/三个按钮切换、铃铛/箭头联动、隐藏暂停和按需加载。
- 另做 12 轮 Live2D/精灵往返切换。每轮主动回收 JS 后，始终为 1 个文档、65 个事件监听；Live2D JS 堆约 5.3–5.5 MiB，渲染进程私有内存约 148–159 MiB。没有发现文档或监听器逐轮增加。
- 单独冷启动刻晴，无 Pixi、无 Core，命中检测与透明穿透通过。该测试渲染进程私有内存约 41 MiB，工作集约 181 MiB；短时 CPU 采样可见约 0.14%，隐藏约 0.007%，隐藏后动画帧不再推进。
- 使用原测试数据更新实际实例，156 份聊天记录校验一致，原形象与缩放选择保留。

以上进程数据来自 Windows、硬件加速和独立测试窗口；不包含主窗口或整个 Electron/GPU 进程树，不能等同于全应用占用。连续换装的瞬时工作集会高于回收后的私有内存。短时检查不能证明长时间运行、所有驱动及导入模型均无泄漏，仍应保留长时间压力测试。
