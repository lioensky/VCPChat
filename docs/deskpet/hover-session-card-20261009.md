# 桌宠悬停和会话卡片

基于 `lioensky/VCPChat feat/deskpet-live2d-v1`（75090bda）。

底部胶囊默认保持显示，作为稳定的打字、说话和会话动态入口。拖动角色时暂时收起，放下后恢复；命中范围采用 CSS 像素，透明窗口其他位置仍穿透。常驻胶囊不阻止角色待机溜达。

默认收起头顶会话面板，铃铛数字按会话统计正在运行或有未读动态的数量，同一话题多个请求不重复计数。点击铃铛展开白色叠卡，按钮变为向上箭头，再点收起。卡片展示真实请求对应话题的标题和思考、回复、工具、完成、取消、错误状态；点击卡片打开准确话题，独立停止按钮停止所选请求。多个会话可通过左右按钮或方向键切换，展开期间选中会话不会被其他流式 token 抢走。Esc 收起并将焦点还给铃铛。

首次尚无请求时铃铛无角标，展开显示“暂无会话动态”。已结束但未查看的动态保留通知；查看且已完成后清除角标，仍运行的会话继续计数。最近保留12条已结束请求，运行中请求保留；换装后从主进程内存快照恢复，面板默认收起。状态不写聊天记录。审批优先占用头顶空间，保留回复正文/错误/审批，工具和纯状态提示统一放在会话卡片。

回归覆盖铃铛角标、会话去重、展开收起、稳定选择、未读清除、点击话题、精确停止、并发、异步标题及换装快照。旧窗口控制测试的固定短等待改为等待可观察状态，并在断言失败时清理窗口定时器，避免测试套件挂起。

新交互在真实 Electron/Cubism Core、200% 缩放、独立数据下验证，女仆及 Q 版截图检查。光标坐标受控输入真实主进程50 ms轮询，不移动物理鼠标；多显示器跨屏仍需人工体验。Core、聊天副本和原始运行日志不提交 Git。
