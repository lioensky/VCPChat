# 桌宠悬停和会话卡片

基于 `lioensky/VCPChat feat/deskpet-live2d-v1`（75090bda）。

收起的脚边横条现在能通过悬停展开。隐藏横条、胶囊及变形动画使用同一块有限的 CSS 像素命中范围；透明窗口其他位置仍穿透。拖动结束后重新核对悬停状态，避免一直保留旧命中值而不展开。

头顶增加白色会话卡片，展示真实请求的会话标题及思考、回复、工具、完成、取消或错误状态，点击打开准确的话题。归属来自聊天请求的 agentId/topicId；标题从对应助手配置读取，文本使用 textContent。多个请求并发时优先展示最新仍在运行的一条，并提示请求数量；该条结束后回到其他未完成请求。换装重载能恢复主进程内存中的状态快照，标题异步返回不能覆盖较新的请求。

首次启动且尚无请求时显示助手名称和“等待新会话”；发出消息后开始跟随会话。状态不持久化到聊天记录。审批出现时暂时隐藏会话卡片，优先保留审批按钮的空间。

验证：227 项桌宠测试通过；66 个聊天合约、863 个生成事件检查通过。修正了两个已有测试的固定等待时间，改为等待窗口创建及甩动落地的可观察状态。

真实 Electron/Cubism Core、150% 缩放、独立测试数据验证通过：三轮横条悬停/胶囊移动/离开收起、输入条点击、话题标题、工具状态、并发完成后回退、点击打开原话题、换装状态恢复。光标坐标受控输入主进程的真实 50 ms 轮询，不移动系统物理鼠标；多显示器实际跨屏行为仍需人工体验。女仆及 Q 版截图已检查。验证用 Core、聊天副本和运行日志均不提交 Git。
