# 桌宠 Live2D 初版（内置 Nova）

## 包含什么

- **桌宠：** 让任意助手待在桌面上，可以直接在桌宠上打字或说话（经主窗口发送，历史照常保存），回复以气泡显示，表情和动作跟着回复的情绪变。支持 Live2D、网格立绘、Codex 精灵动画、差分立绘和头像。默认角色大小在之前基础上缩小 15%，控件大小保持可点击；手动调过的大小会迁移，脚底位置保持。
- **内置形象：** Nova 女仆全身、简洁 Q 版 Live2D（`assets/deskpet/nova/`），以及 Codex 精灵刻晴、乐奈（`assets/deskpet/codex/`）。名为 Nova 的助手默认用女仆；右键「换装」或全局设置「桌宠」分区里切换，每个助手分别记住选择。其他助手默认用自己的素材（没有就显示头像），也可以手动选 Nova 或精灵。
  - 女仆：12 套独立表情（含开心笑眼、腮红、生气/难过的眉眼），眨眼、视线、口型、物理。
  - Q 版：11 套表情、8 个手势（挥手、敬礼、比心、喝茶、打字、耸肩、叉腰、欢呼）。
- **桌宠功能：** 拖动、甩出、贴边与藏边、按元音变口型的 TTS 朗读、工具调用卡片与审批、主动搭话、闲聊（默认关）、睡眠和闲时小动作、点头/点身体的反应、免打扰、鼠标穿透、托盘菜单、快捷键、启动恢复、拖文件导入形象。
- **侧栏首页立绘与情绪模块：** 桌宠依赖的情绪导演（`modules/emotion`）和每个助手的持久心情；侧栏首页渐隐立绘支持动图和视频，表情差分默认关闭。

详细说明见 `DeskPetmodules/README.md`。

## 安装 Cubism Core（Live2D 必需）

Live2D Cubism Core 是 Live2D 的专有组件，**不进 git 仓库**：安装依赖和打包时从 Live2D 官网下载，发布的安装包随应用附带（见 `vendor/live2d-cubism-core/README.md`）。没有 Core 时女仆和 Q 版自动显示各自的立绘；刻晴、乐奈和导入的精灵形象无需 Core。

1. 打开全局设置 →「桌宠」→「Live2D 支持」。
2. 点「同意并下载」：从 Live2D 官网下载 Cubism SDK for Web 5-r.4，只取出 Core 装好，正在用立绘代替的桌宠自动换回 Live2D。
3. 连不上官网时，自己从 https://www.live2d.com/sdk/download/web/ 下载 SDK（必须是 **5.x**，6.x 渲染引擎还不支持），点「选择本地文件…」选压缩包或其中的 `live2dcubismcore.min.js`。

安装前会在隐藏页面里试加载一遍，坏文件和 6.x 不会替换已经能用的 Core。

## 怎么用

选中 Nova，点聊天头部的爪印按钮（或 `Ctrl+Alt+Shift+P`）打开桌宠；光标停在 TA 身上就能打字，`Ctrl+Alt+Shift+M` 叫出 TA 并打开输入框。右键菜单有换装、朗读开关、设置等。

## 导入 Codex 桌宠

在全局设置「桌宠」中点「导入形象」，选择素材包里的 `pet.json` 或 ZIP；也可将整个素材文件夹拖入形象列表。`pet.json` 与它引用的 PNG/WebP 精灵图需放在同一个包内。标准命名的 `spritesheet.png` / `spritesheet.webp` 也可以单独导入。

兼容 v1（1536×1872，8×9 格）和 v2（1536×2288，8×11 格），每格 192×208；未写版本时按标准图尺寸识别，明确写出的版本必须匹配。九种动画对应待机、左右拖动/移动、挥手、跳跃、失败、等待审批、工作和检查；v2 另有 16 个视线方向。精灵动画不需要 Cubism Core，也不依赖 WebGL。它使用原画已经提供的逐帧动作，没有额外生成 Live2D 式的连续口型。

导入会复制素材到该助手自己的形象目录，原始 Codex 素材包保持原样；导入的第三方素材应由使用者按其许可使用。应用另附用户提供的刻晴、乐奈精灵包，安装后可直接选择，无需导入。

## 许可

- Nova 女仆与 Q 版的美术和两套 Live2D 模型是本项目自有素材，随应用分发。模型由开源工具 PSD2Live（GPL-3.0）在本地导出，仓库不含该工具的代码。
- 刻晴、乐奈精灵由用户提供的 Codex 桌宠包收录，保持原始精灵图及 `pet.json`。
- Cubism Core 不进 git 仓库（见上）。渲染引擎的许可见 `vendor/live2d/untitled-pixi-live2d-engine.LICENSE`。

## 已知问题

- Q 版：眼珠移动幅度和身体转角较小；鞋子有接缝；歪头 ±4° 时内侧头发偶尔有一条很淡的细线；手势开始和结束时手臂是瞬间切换的。
- 女仆：放大 3 倍看，刘海下会透出很小的眉毛碎线；女仆下颌线内侧有一道很淡的深色边。
- 模型由 PSD2Live 自动绑定，转头幅度比手工绑定的模型小；后续可在 Cubism 编辑器里细化。
- 软件渲染（没有可用显卡）时 Live2D 也能跑，但更耗 CPU。
