# 桌宠动态模型能力控制

## 提示词

只注入控制语法、能力编号和资源名称，不注入模型名、作者或身份信息。
仅对已就绪、实际使用 Live2D 后端且能力目录与当前形象一致的桌宠注入专属能力。
原有通用动作继续保留。

能力名称取自模型声明、VTube Studio 快捷键或文件名，不使用额外模型推理生成解释。
编号由模型路径、相对资源路径和资源内容生成，防止其他模型或已更改资源误用旧编号。
编号是不透明标识，不应凭示例自行编造，必须复制本次提示词中的清单。

## 语法

沿用情绪注释：情绪后斜杠接一个能力编号或通用动作。
多个调用以加号连接；末尾强度可省略，默认 0.7，有限数值限制到 0–1。
强度无法识别时保留情绪和调用，回退默认值。
表情参数使用强度；文件动画按作者原始曲线播放，不强行缩放自定义参数。
通用动作保持原有参数曲线幅度。

同一标记最多取八个不重复调用。未知编号忽略，不按近似名称或任意路径执行。
同一批显示出来的标记只执行最后一条，避免短时间连续抢动作。
触发时间沿用气泡显示／朗读句子进度，标记不会读出来。

## 资源发现

按模型声明、VTube Studio 配置、模型根目录散落文件的顺序发现并去重。
所有补充资源通过真实路径校验，限制在模型目录内部。
最多发现 200 项候选，每份资源受已有本地 JSON 大小限制。
表情验证参数列表；动画验证曲线列表和时长。
从现有换装分类中识别出的衣服、发型和配饰不进入对话能力目录。
待机、面捕丢失和追踪丢失动画不进入对话能力目录。
名字分类为启发式，不保证能够理解所有作者的私有命名。

运行时补齐内存中的模型定义，不写回用户原始模型与 VTube Studio 配置。
动画按独立资源组和固定索引调用，不随机抽取同组动画。
不自动把未声明的待机动画设为默认待机。

## 临时表现

表情／姿态组合显示约四秒，最后 0.4 秒淡出。
每帧从默认参数合成，不跨帧累加；同参数按能力目录顺序合成。
退出或替换时只清理曾控制的参数，不创建模型不存在的参数。
该层在情绪和生活参数之后、持久换装之前，因此用户换装优先。
当前不是完整的 VTube Studio 快捷键模拟器，不复现键盘状态、外部道具或任意快捷键动作。

文件动画关闭循环，保持作者原始时长。
显式动画期间抑制随机生活动作和情绪动作的抢占，用户互动仍可打断。
显式动画保护窗口最长 30 秒。

## 验证边界

自动测试覆盖目录发现、越界路径拒绝、动态提示词隔离、异常强度、
流式切分、旧语法兼容、一次性触发、参数混合和自动恢复。
纯测试不等价于真实 WebGL 渲染验收；新增模型仍应在应用中确认视觉效果与作者参数约定。
