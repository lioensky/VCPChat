# 桌宠语音唤醒

## 使用

1. 在全局设置的语音设置中安装现有 SenseVoice 本地识别资源包。
2. 打开全局设置 → 桌宠，选择目标助手。
3. 在“语音唤醒”区下载唤醒模型，或导入已解压的中文 wenetspeech mobile 模型目录。
4. 填写唤醒词，例如“小克小克”“诺娃诺娃”“nuowanuowa”。
5. 推荐使用明确声调的拼音，例如“nuo4 wa2 nuo4 wa2”。多个别名用竖线分隔。
6. 填写回应文案，点击“生成语音”，再点击“试听语音”检查。
7. 开启该助手的语音唤醒，点击“保存唤醒设置”，保持该桌宠可见。
8. 呼叫唤醒词，等待回应结束后说话；持续静音约 1.2 秒后转写。
9. 可选择自动发送，或将识别文字放入桌宠输入条确认。

回应语音复用助手的主 TTS 音色、语速和导演提示词。
生成语音可能调用已配置的外部 TTS 服务；日常唤醒播放使用已保存的本地音频。
未生成回应音频时，唤醒仍可通过桌宠文字提示进入录音。
文案、音色、语速、导演提示词或服务配置变化后，需重新生成回应音频。

## 运行方式

- 与 SenseVoice 共用 sherpa-onnx-node 运行时，不新增第二套 ONNX Runtime。
- KWS 使用独立子进程，避免 SenseVoice 同步 CPU 转写阻塞实时监听。
- 多个助手共用一个后台麦克风采集窗口和一个 KWS 实例，关键词映射到对应助手。
- 仅配置开启且可见的桌宠参与监听；没有参与目标时释放采集窗口。
- 唤醒时并行预热 SenseVoice，并播放本地回应。
- 首版为半双工：回应期间不接收正式输入，回应结束后留出约 250 毫秒回声尾部。
- 实时 Silero VAD 检测尾部静音；8 秒未开口则取消，录音最长约 60 秒。
- 锁屏、睡眠、免打扰、桌宠隐藏和退出时停止监听。
- 桌宠手动录音期间暂停后台唤醒；手动录音结束后恢复。
- 应用窗口正在出声时暂停关键词检测，避免朗读或试听自唤醒。
- 自动发送使用独立文本请求，不携带原有草稿、附件或新话题开关。
- 助手忙碌或发送失败时将文本保留在输入条，不静默丢弃。

## 模型与本地数据

模型资源存入应用数据目录下的 VoiceModels/kws。
每个助手的唤醒配置及持久回应音频存入应用数据目录下的 deskpet/wake。
这些是运行数据，不需要提交到 Git。

本地导入与在线下载均校验固定版本的四个文件及 SHA-256。
在线下载使用稳定 GitHub release 地址，不依赖短期签名 URL。
安装只提取固定白名单成员，系统需要支持 bzip2 的 tar；缺少工具时可使用本地导入。
当前下载不支持断点续传，失败后重试会重新下载。

拼音输入表示中文读音，不是英语。
无声调拼音会展开受限声调候选，重复音节保持相同读音；单别名最多 64 个候选。
连写拼音按最长候选切分，重复短语优先；有歧义时应以空格和数字声调明确读音。
不同助手不能配置相同声学读音。

## 已验证

- 桌宠完整测试集：316 项通过。
- 设置结构测试：30 项通过。
- 新增测试覆盖中文/拼音、读音冲突、模型导入校验、回应音频持久化与配置失效、
  生成失败保护、WAV 编码、状态机路由和隐藏后取消迟到转写。
- 使用开发者提供的真实 mobile 模型，在 Node 子进程中正确命中官方测试音频关键词。
- Electron 隐藏采集窗口使用虚拟麦克风通过冒烟测试，停止后无遗留窗口。

冒烟测试入口：scripts/deskpet/test-wake-electron.cjs。
终端若继承 ELECTRON_RUN_AS_NODE，需要先对测试进程清除该环境标记。
