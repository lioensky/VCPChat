# Tavern-SRPG

SillyTavern 战棋（SRPG）扩展。在棋盘上操作战斗，由插件计算结果，再把结果以**用户消息**的形式交给 LLM 描写。

- 自定义单位数值：HP / ATK / MATK / DEF / MDEF / AGI / MOV / 韧性 / 视野，另有攻击射程、攻击类型、飞行、AI 行为和技能
- **兵种与克制**：自定义兵种（侦察、坦克、战士……），为每对兵种设置伤害倍率、命中修正和韧性消耗倍数；提供「战士 / 坦克 / 侦察 / 射手」模板和克制总览表
- **剧情同步**：插件自己配置的模型定期（如每 3 轮）或在你点击时读取聊天记录，发现学会新能力、换装备、新同伴加入或即将开战时，更新角色的属性、技能与特质，或按剧情设计关卡，确认后应用（成长可设为自动并撤销）。聊天 AI 不需要写任何标记，插件不会打断或改写正文
- **AI 设计助手**：用 SillyTavern 当前的模型、SillyTavern 的连接配置或自己填写的 OpenAI 兼容 API，读取世界书和角色卡设定，自动设计整场战斗、地图、单位、地形和兵种，预览后导入资料卡
- **战争迷雾**：按地图开启，只能看到己方视野内的敌人；视野受单位属性、地形（高地、森林隐蔽、城墙遮挡）影响，移动时可能遭遇伏击，敌方 AI 也可以只追踪看得见的目标
- 韧性：每次防御或反击消耗 1 点，耗尽后只能承受全额伤害，己方阶段开始时回满；集中火力或远程消耗可以打穿目标的招架
- 常驻特质：自定义名称和描述，组合属性加减（百分比或固定值）、阵营回合开始恢复HP（百分比或固定值）、范围内吸引AI优先攻击；提供「强壮 / 再生 / 欠揍」快捷模板，编辑时先选择一个特质
- 命中判定：由敏捷差和地形闪避决定命中率，攻击、反击、技能都可能落空
- **对空规则**（可选）：飞行单位只能被标记为「对空」的普通攻击（如弓箭手）或技能（如火球）以及其他飞行单位打到
- 技能分物理伤害 / 魔法伤害 / 辅助三类，带回合冷却；可附加预设效果（攻防升降、嘲讽、中毒、眩晕、恢复 HP 等）
- 单位可以**绑定世界书条目**：描写时自动带上条目关键词以触发该条目，也可以把条目内容注入战场状态
- 自定义地形（河流、平原、峡谷……）：移动消耗、步行/飞行能否通过、减伤、闪避加成、回合回复、给 LLM 的描述
- 地形伤害：落脚扣血、阵营回合开始扣血，支持固定值＋最大 HP 百分比；自带熔岩预设，可设置是否伤害飞行单位
- 递减防御伤害公式：防御平滑减伤、技能倍率线性生效，物理和魔法分别计算，仍可选择旧公式
- 战斗手动修改：放置 / 撤除 / 移动单位、调整 HP 和数值、复活 / 重置技能、修改地形、击败场上敌人，支持撤销
- 「仅结算回合」：由内置 AI 结算，不调用 LLM、不发送消息；保留行动供稍后手动发送
- MAP攻击：从角色向上下左右延伸的直线攻击，或指定地块为中心的范围攻击；覆盖目标同时受伤，不反击，可设置友军误伤
- 后手武器：大剑 / 重武器主动普通攻击时，能回击且不是后手的目标先出手；先被击败则攻击取消
- 行动过程：我方与敌方逐格移动、攻击闪烁、伤害 / 回复数字；可调速度、关闭或随时跳过
- 交战确认：选择攻击对象后先查看命中伤害、命中率、期望伤害与反击风险，可单独战斗或立即让 LLM 描写这次交战
- 战斗回溯：每个我方阶段开始时自动存档，可回到之前的回合补录剧情后继续；聊天记录不受影响，回溯前的进度也会保存
- 暂停战斗：保留棋盘、回合、HP、技能冷却及待发送行动，暂停提示词注入、宏/工具查询和战场变化同步；关闭窗口或刷新后可继续
- 受击反应：敌人攻击我方角色时暂停，选择反击或防御；无法反击时只提供防御，防御默认额外减伤50%；支持「反击并生成描写 / 防御并生成描写」，回合结算完成后详细描写选中的交战，其他行动作为背景信息带过
- 地图编辑器：画地形、放置我方/敌方/友军单位
- **资料卡**：单位、地形、地图和战斗规则打包成资料卡，可以绑定到角色卡或群组，打开聊天时自动切换；还能写进角色卡，随卡分享
- **仅显式绑定后启用**：未绑定角色 / 群组不使用默认卡，不注入、不处理指令、不改变聊天消息显示；一张资料卡可以绑定多个角色
- 三种任务：**歼灭战**、**守城战**、**进攻战**，敌人的寻路目标随任务变化；可以设置敌人（或友军）定期增援
- 描写模式可调：是否描写移动、普通攻击、技能、敌人行动、友军行动、回合切换
- 自由输入的文字**不会改变棋盘**
- LLM 也能影响战场：担任敌方 / 友军的指挥官选择行动，或在剧情同步时读出剧情对战场的改变（落石、撤退、援军、地形变化……），由战斗系统校验后执行。都用插件配置的模型在后台进行，不经过聊天
- **单位资料（类似世界书）**：开关开启后，资料卡里设定的角色能力在战斗之外也提供给聊天 AI，提到名字或别名时自动附上
- LLM 可以读取完整战场：地图网格、每个单位的 HP / 属性 / 状态 / 技能冷却 / 位置 / 敌我距离；支持自动注入、`{{srpg}}` 宏和函数调用查询

## 安装

**推荐：** 在 SillyTavern 中打开「扩展」面板 →「安装扩展」，输入下面的地址：

```
https://github.com/DoubleOpenFreezer/Tavern-SRPG
```

**手动安装：** 下载或 `git clone` 本仓库，把整个目录放到下面任意位置，然后刷新 SillyTavern：

- `SillyTavern/data/<用户名>/extensions/Tavern-SRPG/`
- `SillyTavern/public/scripts/extensions/third-party/Tavern-SRPG/`

更新：在「扩展」面板里点「更新」，或在该目录下 `git pull`。

打开方式：点击屏幕右侧的**悬浮按钮**（♞，可以拖到任意位置）；也可以用输入框左侧的魔杖菜单 →「Tavern-SRPG 战棋」，扩展设置里的「打开战棋面板」，或输入 `/srpg`。

未绑定的聊天不会显示悬浮按钮，也不会自动打开战棋。首次使用时，请从魔杖菜单、扩展设置或 `/srpg` 手动打开「资料卡」，为当前角色绑定资料卡后再开始战斗。只选择资料卡进行编辑不会启用当前聊天。

**界面布局**
- 完整窗口可以拖动、调整大小，包含战场、资料卡、单位、地形、地图和设置。
- 点击面板右上角的「缩小为战斗小窗」按钮，只保留地图和必要操作：开始战斗、移动、攻击、技能、待机、撤销、结束回合和发送行动。
- 小窗高度随内容变化，可拖到方便的位置，不会挤压聊天区域；点击「恢复完整窗口」返回之前的编辑页和窗口尺寸。
- 小窗中的「处理剧情提议」会打开完整战场页，查看并确认 LLM 提议的变化。
- ✕ 收起窗口，再点悬浮按钮打开。手机上完整窗口全屏，小窗仍保持紧凑。

## 使用流程

0. **资料卡**页：选择或新建一张资料卡，并把它绑定到当前角色（见下方「资料卡」）。下面几步编辑的都是正在使用的资料卡。
1. **地形**页：按需修改或新增地形。自带平原、森林、山地、河流、峡谷、桥梁、沙地、堡垒、城墙。
2. **单位**页：创建我方、敌方、友军单位，填写数值和技能；在「世界书绑定」里选择世界书和条目。需要克制关系时，先在**兵种**页建立兵种，再在单位里选择兵种。
3. **地图**页：新建地图，用「画地形」绘制（可按住拖动），用「放置单位」摆放单位（同一单位可以放多个，自动编号 A、B、C）；在地图下方选择任务类型，用「增援点」工具或「添加增援」设置增援。
4. 打开一个聊天，在**战场**页选择地图 →「开始战斗」。战斗进度保存在当前聊天的元数据里，每个聊天互不影响。
5. 在棋盘上操作：
   - 点击我方单位 → 蓝色是可移动范围，红色是移动后可攻击的范围
   - 点击蓝色格子移动（或点「原地行动」）→ 选择「攻击」/ 技能 /「待机」/「撤销移动」
   - 攻击：点击闪烁的敌人；悬停时显示预计伤害和反击
   - 技能：点击技能后选择目标格，范围技能会以黄色显示影响区域
   - 右键取消选择；顶部「撤销」可撤回本回合的操作
6. 「结束回合」→ 敌方与友军由 AI 行动 → 自动整理本回合的全部结果，按设置预览或直接发送。也可以随时点「预览并发送」只发送已经发生的行动。
7. 「补充要求」输入框里的文字会作为【用户补充要求】附在消息末尾。开启「附带主输入框中的文字」后，主输入框里已有的文字也会一起带上。

**快速结算与手动修改**

- 点击「仅结算回合」可跳过叙事请求。即使启用了 LLM 指挥官，该次也使用内置 AI；待发送行动会累积，需要时再点击发送。也可以在设置中关闭「结束回合时自动整理发送」。
- 完整窗口和战斗小窗都有「手动修改」入口。开启后，选择工具并点击棋盘，即可放置、撤除、移动单位或替换地形；选择单位后可调整 HP、最大 HP、攻击、防御、敏捷、移动、射程、韧性、阵营、飞行和行动状态。
- 「满血 / 重置行动技能」可复活所选单位、解除状态、恢复技能次数与冷却；「击败场上全部敌人」可清理残局，地图中的后续增援仍然有效。
- 修改只影响当前战斗，可用「撤销」恢复；胜负会重新判定，下一次发送行动时会包含修改说明。手动移动和放置不触发落脚伤害。

**熔岩与伤害公式**

- 在「地形」页点击「添加熔岩」，旧资料卡也能添加。预设落脚扣 5 HP，所属阵营回合开始扣最大 HP 的 10%；飞行单位默认免疫。地形编辑器可以修改固定伤害、百分比伤害及飞行免疫。
- 落脚伤害只计算移动终点，沿途格子不扣血；原地行动不重复触发。地形伤害可致死、不受防御减免；回合伤害先于地形回复结算。
- 新默认伤害为 `攻击 × 威力% × 防御基准 ÷（防御基准＋防御）`，基准默认 12：防御 12 减伤 50%，防御 24 减伤约 67%。物理使用 ATK/DEF，魔法使用 MATK/MDEF，再计算地形、随机浮动和最低伤害。
- 首次升级会将资料卡中的旧默认减法公式切换为递减防御；比例公式保留。可在「设置 → 战斗规则」调整防御基准或切回旧公式。

**MAP攻击、后手武器与行动过程**

- 在「单位 → 技能」中选择一个伤害技能，将「攻击方式」设为「MAP：直线路径攻击」或「MAP：指定地块范围攻击」。物理 / 魔法类型仍决定使用的攻击、防御属性。
- 直线模式设置「直线长度」，例如 3 格；战斗中点击角色上下左右方向上的任一覆盖格，攻击从角色向该方向延伸的整条路径。路径穿过单位和地形，在地图边界停止，不支持斜线。
- 地块范围模式设置施放射程和范围半径；选择射程内任意地块，攻击中心周围按格子距离计算的菱形区域。半径 1 包含中心及上下左右；可以选择空地，范围内没有目标时也消耗技能。
- MAP攻击不触发反击，也不触发后手交换；命中、威力、冷却、次数仍遵守技能规则。默认影响敌我全部单位和建筑，但不伤害施法者；「MAP作用对象」可改为仅敌方。悬停时显示整片区域及目标伤害预览，敌方 AI 会计入误伤风险。
- 在「单位 → 普通攻击顺序」选择「后手：大剑 / 重武器」，并可填写武器名称。主动普通攻击时，如果目标能回击、没有眩晕且不是后手角色，则目标先攻一次，自己存活后再攻击；不再追加一次普通反击。双方都为后手时由主动方先攻；目标是建筑或无法回击时也由主动方先攻。关闭普通反击不取消后手先攻规则。
- 我方行动、敌方 / 友军回合、LLM 指挥官行动和「仅结算回合」都会显示过程。棋盘上逐格播放移动、显示先攻 / 攻击 / 反击顺序、闪烁覆盖区域、显示伤害或回复数字。过程不重复判定伤害，期间锁定操作；「跳过过程」直接显示已结算结果。
- 「设置 → 界面」可关闭「显示移动和攻击过程」或调整过程速度。切换聊天会停止旧战斗的过程，避免影响新聊天。

**交战细节与反击 / 防御**

- 我方选择普通攻击目标或伤害技能的目标地块后，先出现「战斗确认」。显示命中时伤害、命中率、期望伤害、对方存活后反击的伤害与命中率；后手武器会标明对方先攻的风险。取消不会结算伤害，也不消耗此次攻击。
- 「战斗」只结算；「战斗并生成描写」结算并立即发送本次交战结果，触发 LLM 回复，不受全局发送预览模式影响。本次交战会详细描写；之前尚未发送的行动作为「背景信息」附在同一条消息里，发送后待发送列表清空。所有发送方式都只包含上次发送之后发生的行动。
- 期望伤害是忽略随机浮动的近似值，按命中伤害×命中概率估算，并计入先被击败或目标被击败导致不能出手的风险；确认后才执行实际随机判定。
- 敌方被攻击时默认选择可用的反击，不能反击时防御。普通伤害技能也可以被反击，MAP不能被反击。建筑无法主动防御或反击，不享受角色的额外防御减伤。
- 敌方移动到攻击位置后、扣血前，会暂停让受攻击的我方角色选择「反击」「防御」或「承受」。反击受射程、眩晕、普通反击设置与 MAP 限制；不能反击时只显示「防御」。防御放弃反击并降低本次伤害，默认减伤50%，仍受最低伤害规则约束。
- 多目标技能为每个我方目标分别选择反应，然后一并结算伤害；选择反击的存活目标依次回击，施法者倒下后不再继续反击。
- 「设置 → 战斗规则」可调整防御减伤比例；「设置 → 界面」可关闭受击手动选择，自动采用可用的反击，否则防御。静默回合也遵守受击选择，但不会请求 LLM。
- **韧性**：每个角色有韧性（默认 2，可在单位编辑器中修改；建筑没有韧性）。每次选择防御或反击消耗 1 点，技能未命中也会消耗；耗尽后不能防御也不能反击，只能承受全额伤害。韧性在该单位所属阵营的阶段开始时回满，所以一个回合里集中攻击同一个目标、或先用远程攻击消耗它的韧性，就能让后续攻击打出全额伤害。战斗确认、受击选择、单位卡片和 LLM 读取的战场信息都会显示剩余韧性；受击窗口始终提供「承受」和「承受并生成描写」：有韧性时也可以主动承受，不防御也不反击、承受全额伤害，但不消耗韧性，留给后面更危险的攻击；我方韧性耗尽时只剩这两项。更新前已经开始的战斗按资料卡补上韧性。
- **韧性系统开关**（设置 → 战斗规则，属于当前资料卡）：「所有单位」（默认）；「仅我方角色」只有我方单位有韧性；「关闭」所有单位都没有韧性。不受韧性约束的敌方 / 友军只在能反击时反击，打不到就直接承受，不会防御，因此远程攻击近战敌人能打出全额伤害；我方关闭韧性后可以不限次数地防御、反击或承受。界面和 LLM 读取的战场信息只为受约束的单位显示韧性。修改后对进行中的战斗立即生效。
- 「取消本次回合」会恢复结束回合前的棋盘；关闭窗口会取消正在等待的反应，切换聊天不会把旧战斗结算到新聊天。

如果直接在聊天输入框打字发送，棋盘不会有任何变化，LLM 只会做叙事描写；注入的战场状态会告诉它当前的 HP 和位置。

发送到聊天中的战斗信息默认显示为折叠的「战斗记录」卡片，点击标题展开 / 收起。这里只改变聊天显示，LLM 仍然读取完整信息；编辑、复制消息时也保留原文。重新打开聊天后，已有的战斗记录也会自动折叠。

## 发给 LLM 的消息示例

```
【SRPG 战斗系统】以下行动结果已由战斗系统计算完成，请据此生动地描写战斗过程。……
〔战场：河畔之战｜第 1–2 回合〕

【需要描写的行动】
· 骑士〈罗兰〉 从 (2,4)平原 移动到 (7,4)桥梁。
· 骑士〈罗兰〉 对 哥布林A 发动物理普通攻击，造成 9 点伤害（哥布林A HP 18→9）；哥布林A 反击，造成 1 点物理伤害（骑士 HP 32→31）。
—— 第 1 回合 · 敌方阶段 ——
· 哥布林弓手 对 骑士〈罗兰〉 发动物理普通攻击，造成 1 点伤害（骑士 HP 31→30）。

【背景信息（无需详细描写，一笔带过或略过即可）】
· 哥布林B 从 (9,6)平原 移动到 (7,5)桥梁。

【用户补充要求】
着重描写罗兰守桥时的心理
```

`〈罗兰〉` 是绑定世界书条目的第一个关键词，用来触发该条目。

## 对空规则

「设置 → 战斗规则 → 飞行单位」默认为「可以被任何攻击打到」。改为「只能被对空攻击或飞行单位打到」后：

- 单位编辑器勾选「普通攻击可对空」（例如弓箭手），它的普通攻击和反击才能打到飞行单位；技能编辑器勾选「可以对空」（例如火球、箭雨），该技能才能打到飞行单位。示例资料卡中哥布林弓手和法师的火球术已经勾选。
- 飞行单位之间总是可以互相攻击。
- 不能对空的单位不能选择飞行单位作为普通攻击或单体技能的目标，也不能反击飞行单位；不能对空的范围技能和 MAP 攻击不会波及范围内的飞行单位（包括飞行友军）。飞行单位攻击不能对空的地面单位时不会被反击。
- 援护：攻击方打不到的飞行单位不能替队友承受这次攻击。
- AI 不会去追击打不到的飞行单位；评估危险（逃跑、远程游击）时，不把打不到自己的敌人算作威胁。
- 单位卡片显示「飞行 · 需对空」「对空」标签，LLM 读取的战场信息、技能说明和 AI 设计助手也会写明对空能力。
- 规则属于资料卡，修改后对进行中的战斗立即生效；「手动修改」中可以临时切换单位的对空能力。

## 兵种与克制

在「兵种」页新建兵种（例如侦察、坦克、战士、射手），然后在「单位」页为单位选择兵种。点「添加模板」可以一次加入「战士 / 坦克 / 侦察 / 射手」四个兵种和一套克制关系作为起点。

每个兵种可以为「攻击其他兵种时」设置三项数值，未设置的组合不受影响：

| 项目 | 默认 | 作用 |
| --- | --- | --- |
| 伤害倍率 % | 100 | 最终伤害乘以该倍率（在防御计算之后、地形减伤之前），150＝伤害×1.5 |
| 命中修正 % | 0 | 加在命中率上 |
| 韧性消耗倍数 | 1 | 被攻击方每次**防御或反击**消耗的韧性；2＝一次耗两点（剩余不足时扣到 0），0＝招架不消耗韧性 |

- 关系有方向：「骑兵 → 弓兵」和「弓兵 → 骑兵」分开设置。普通攻击、伤害技能（含 MAP）和反击都按「出手方 → 承受方」的兵种计算；援护时按援护者的兵种计算。
- 页面下方的**克制总览**以表格显示所有组合（行＝攻击方、列＝防守方），红色为克制、蓝色为劣势，点击格子切换编辑的兵种。
- 战斗确认、受击选择中会显示「兵种克制　坦克→战士：伤害120%、命中+10%」；AI 估值、预计伤害都已计入克制。
- 兵种描述和克制关系会写进 LLM 读取的战场信息，战斗描写中也会注明「（兵种克制：伤害150%）」。
- 建筑也可以有兵种，例如给城门设「建筑」兵种，再让「攻城」兵种对它造成 200% 伤害。
- 开战时复制兵种设置，修改资料卡不影响进行中的战斗；更新前开始的战斗会在打开时补上兵种。手动修改中可以临时改变单位的兵种。

## 战争迷雾

在「地图」页的任务设置下方勾选「开启战争迷雾」。内置示例「夜袭森林」就是一张迷雾地图：哥布林埋伏在树林里，斥候（视野 7）负责探路，「照明弹」可以照亮一片区域。

**视野**
- 每个单位有「视野」属性（默认 4 格，建筑默认 0；建筑设为大于 0 可当作瞭望塔）。我方与友军共享视野，按格子距离计算。
- 地形的三个视野属性（「地形」页 → 视野）：**视野加成**（山地 +2、堡垒 +1）；**隐蔽距离**（森林 1：站在森林里的单位只有相邻的敌人才能发现；飞行单位不受隐蔽）；**遮挡视线**（城墙：视线不能穿过，擦过墙角时可以看到）。
- 效果：「视野上升 / 视野下降」（技能或特质），「暴露行踪」（减益：迷雾中所有敌人都能看到它）。

**规则**
- 地形始终可见；视野之外的格子变暗，看不到的敌人不显示，也不能被选为普通攻击或单体技能的目标。范围技能和 MAP 攻击可以朝迷雾里打，命中迷雾中的敌人后才会知道。
- **攻击会暴露位置**：攻击或用技能攻击敌人后，攻击者和被攻击者对彼此可见，直到各自阵营的下一个阶段开始。所以从迷雾里放冷箭的弓手，在你的回合可以被找到并反击。嘲讽中的单位也总是可见。
- **伏击**：玩家眼中看不见的敌人所在格是空的；移动路线上撞到它时，单位停在前一个能停留的格子，伏击者暴露。仍然可以行动（例如攻击伏击者）。移动中发现新的敌人或遭遇伏击后，这次移动不能撤销。
- **最后发现位置**：曾经看到、现在看不到的敌人会留下半透明的「?」棋子；再次看到原位置时，如果人已经离开就会消失。
- **敌方 AI 也受迷雾限制**（默认开启，可在地图设置中关闭）：敌人只攻击和追踪看得见的我方单位；看不到任何人时，前往最后发现我方的位置搜索（开战时敌人知道我方的布阵位置），到达后仍然找不到就原地警戒。关闭后，敌人知道所有我方单位的位置，只有我方受迷雾限制。友军 AI 使用我方视野。
- 迷雾中看不到的敌方行动（移动、治疗、中毒等）不播放、不进入待发送列表，也不会发给 LLM，只留一句「迷雾中传来敌军活动的动静」；敌人从迷雾中现身、消失在迷雾中会如实描写。
- LLM 读取的战场信息只包含我方看得见的敌人，并附上「最后发现位置」，提醒 LLM 不要描写看不到的敌人的位置；函数调用查询同样只返回看得见的单位。
- 「手动修改」中显示全部单位（含迷雾中的敌人），也可以临时开关迷雾或修改单位视野；退出后恢复迷雾。

## AI 设计助手

「AI 设计」页可以让 AI 按世界观设计内容，结果先预览，确认后再导入当前资料卡。

**选择模型**（「API 设置」，全局设置）
- **当前 SillyTavern 使用的 API**：直接用聊天正在用的 API 和模型，只发送设计任务（不带聊天记录和角色卡提示词）。生成期间不要同时在聊天里生成。
- **SillyTavern 连接配置**：选择在 SillyTavern「API 连接」页用「连接配置」保存的配置。请求经由 SillyTavern 后端发送，密钥留在 SillyTavern 里；可以让设计用一个模型、聊天用另一个模型，互不影响（需要较新版本的 SillyTavern）。
- **自定义 API（OpenAI 兼容）**：填写 API 地址（如 `https://api.openai.com/v1`，会自动补上 `/chat/completions`）、API Key 和模型，可以点列表按钮获取模型列表。浏览器直接请求可能被跨域（CORS）拦截：可以勾选「通过 SillyTavern 代理转发」（需要在 SillyTavern 的 `config.yaml` 中设置 `enableCorsProxy: true`），或者改用连接配置。API Key 以明文保存在本机 SillyTavern 的扩展设置里，不会随「导出全部」导出。
- 「最大输出长度」决定 AI 最多能写多少；整场战斗或大地图建议 8000 以上。回复被截断时会提示。可以点「测试连接」检查设置。

**世界观资料**
- 默认自动读取当前聊天的世界书：角色卡绑定的世界书（含附加世界书）、群组成员的世界书、聊天绑定的世界书和全局启用的世界书；也可以取消「自动选择」后手动勾选任意世界书。只发送启用的条目，超出「字数上限」的条目不发送。
- 「附带角色卡设定」会发送角色（或群组成员）的描述、性格和场景。
- 「预览发送给 AI 的内容」可以查看完整提示词和字数。AI 还会看到资料卡中已有的地形、兵种、单位和地图，以及伤害、命中、效果预设等规则，用来保持数值平衡、直接引用已有内容。

**设计与导入**
1. 选择要设计的内容：整场战斗（地图＋需要的单位、地形、兵种）、地图、单位、地形或兵种；地图可以指定尺寸，「地图」任务可以选择只用已有的单位和地形。
2. 写下要求，例如「主角一行在夜里穿越精灵森林，被暗影教团伏击，开启战争迷雾」，点「开始设计」。
3. 结果按地图（带棋盘预览）、单位、地形、兵种列出。不合规的内容会自动修正或忽略，并列出修正说明：例如不存在的效果、超出范围的数值、站不住的放置位置（挪到附近空位）、未知地形（换成平原）、与已有内容重名（改名为「名字（2）」）。
4. 勾选要保留的内容，点「导入选中的内容」。导入地图时，它用到的新单位、地形和兵种会自动一起导入；单位写了对应的世界书条目名时会自动绑定该条目。导入后可以在各页面继续修改，地图可以直接开战。
5. 不满意可以写下修改意见，点「按意见重新设计」，AI 会在上一版的基础上修改。也可以展开「原始回复 / JSON」手动修改后「重新解析」。

## 剧情同步

让剧情和战棋数据保持一致：在对话里学会了新能力、换上了新武器、有新同伴加入，或者剧情即将开战时，由 AI 更新角色资料或设计关卡。在「AI 设计」页最上方的「剧情同步」中开启（需要先在「API 设置」中准备好插件使用的模型）。

**和聊天互不干扰**：同步完全由插件自己配置的模型完成。聊天 AI 不会收到额外的说明，也不需要在回复里写标记，插件不会读取它的生成过程，也不会改写消息。插件与聊天唯一的交汇点是战斗描写：需要描写战斗时，插件把结算好的行动填进你的输入框（或直接发送，取决于「发送方式」）。如果「API 设置」选的是「当前 SillyTavern 使用的 API」，同步与聊天共用同一个接口；想完全分开，可以改用连接配置或自定义 API。

**插件模型看到的内容**：只有世界书、角色卡设定（可在「世界观资料」中关闭）、资料卡中的单位与规则、战斗中的战场状态，以及指定楼层的聊天记录。聊天记录分成两部分：「新的剧情」是这次要分析的楼层；之前已经同步过的几楼作为「之前的剧情」附上，只用来理解上下文，不会重复分析。

**什么时候同步**
- **每隔几轮自动同步**（默认每 3 轮）：每收到一条 AI 回复就计一轮，到了设定的轮数就在后台同步，不会阻塞聊天。重新生成、滑动的回复不重复计数。第一次在某个聊天里开启时，从之后的新回复开始计数。
- **只在我点击时同步**：点击面板标题栏的 📖 按钮（角标是上次同步之后的新回复数），或在「剧情同步」中点「立即同步」。
- 两种方式都可以在「剧情同步」中手动指定「读取第 a 楼到第 b 楼」，楼层号就是聊天消息上的 # 编号。「每次最多读取几楼」限制一次读取的长度（超出时只读最近的部分）。「跳过之前的剧情」会把已有的楼层标记为已同步。

**同步的结果**
1. 插件模型一次分析找出角色成长、即将开始的战斗，以及战斗中剧情造成的战场变化（需要在设置页开启，见「LLM 影响战场」）。
2. 成长与关卡列在「剧情同步」里，悬浮按钮显示待确认的数量。点「查看」预览，确认后应用；发现即将开战时，再调用一次插件模型设计关卡。

**角色成长**
- 可以修改已有单位的属性（HP、攻防、敏捷、移动、韧性、视野、射程）、攻击类型、武器名、飞行、对空、兵种、别名；新增、升级（同名技能视为升级）、修改或移除技能；获得或失去特质；也可以加入新同伴（新单位）。
- 预览逐条列出「修改前 → 修改后」，可以只勾选部分修改。不合规的内容会自动修正或忽略并给出说明。
- 「角色成长」可以设为「自动应用」：同步后立即生效并提示，随时可以在列表里「撤销」（恢复资料卡中的单位，移除新加入且没有被地图使用的同伴）。
- 有进行中的战斗时，默认同时更新场上来自同一单位的棋子：提高最大 HP 时当前 HP 也恢复相同数值，新技能立即可用，升级的技能保留冷却；同时在待发送行动里记一条「【剧情成长】」。新同伴不会直接出场。撤销只恢复资料卡，战斗中的变化需要用「撤销」或手动修改恢复。

**剧情关卡**
- 插件模型根据最近的剧情设计接下来的战斗：地点、敌人、出场的我方角色和任务都与剧情一致，地图以剧情中的地点命名。预览后可以只导入，也可以点「导入并开始战斗」直接开战。
- 已有进行中的战斗时不会提出新关卡。

**手动使用**：「AI 设计」页的任务里也有「根据剧情创建关卡」和「根据剧情更新单位」，不开启剧情同步也能用；补充说明可以留空，AI 会自己从最近的剧情里找。手动分析的成长应用后同样会记在列表里，可以撤销。

**重新生成与删除**：已经同步过的楼层被重新生成、滑动或删除时，覆盖这一楼的同步作废，下次从那次同步的起点重新读取；这些楼层上尚未应用的提议也作废（正在进行的同步会被取消）。已经应用的成长不会自动撤销。同步进度和提议保存在当前聊天里，切换聊天后继续处理没完成的关卡。

战场页顶部的 👁 按钮和设置页的「查看 LLM 看到的内容」，可以直接看到 LLM 收到的完整文本。

## LLM 影响战场

LLM 不会直接改数值：它要么从战斗系统列出的合法行动里做选择，要么提出指令，由战斗系统校验后再执行。两种方式都在设置页「LLM 影响战场」中开启，默认关闭。它们都使用「AI 设计」页「API 设置」中配置的模型，在后台单独调用，不经过聊天，也不会要求聊天 AI 输出任何东西。

### ① LLM 指挥官

勾选「指挥敌方」或「指挥友军」后，结束回合时：

1. 战斗系统为该阵营每个单位列出最多 N 个合法行动，例如：「移动到 (8,4) 后普通攻击 骑士[P1]（命中 81%，伤害约 9）」「使用【毒箭】作用于 法师[P2]」「向 城门[P1] 前进」「原地待命」。
2. 一次后台调用（附上战场信息和最近几楼的剧情，不会出现在聊天里），让 LLM 结合剧情和角色性格为每个单位选一个，可以附一句意图：
   ```
   E1: 1 | 为同伴报仇，冲向最近的人类
   E2: 3
   ```
3. 系统按顺序执行。前面的单位行动后，后面的选择可能已经失效（目标倒下、格子被占），这时以及 LLM 没给出选择、写了 0 时，交给内置 AI。
4. 意图会写进战斗描写：`哥布林A 从 (10,4)平原 移动到 (5,4)平原（意图：为同伴报仇，冲向最近的人类）。`

等待期间棋盘会锁定；如果中途切换了聊天，这次敌方回合不会结算。

### ② 战场变化（剧情同步）

勾选「允许剧情同步提出战场变化」并开启剧情同步后，战斗进行中的同步会附上战场状态和指令写法。聊天里的剧情（不是常规的攻击与技能）改变了战场时，插件模型会把变化写成指令：

```
damage E1 5 被落石砸中
move E2 6 5 被冲击波击退
status P1 atk_up 30 2 受到鼓舞
retreat E3 吓得落荒而逃
```

| 指令 | 写法 | 说明 |
| --- | --- | --- |
| 造成伤害 | `damage <单位> <数值> [原因]` | 受「HP 变化上限」限制，默认不能直接击败（最多扣到 1） |
| 回复 HP | `heal <单位> <数值> [原因]` | 同样受上限限制 |
| 附加状态 | `status <单位> <效果> [数值] [回合] [原因]` | 只能用预设效果（中英文名都可以），按回合计时 |
| 解除状态 | `unstatus <单位> <效果\|all> [原因]` | |
| 强制移动 | `move <单位> <x> <y> [原因]` | 目标格必须空着、该单位能站上去 |
| 撤离战场 | `retreat <单位> [原因]` | 离开战场但不算被击败 |
| 新单位登场 | `spawn <单位类型名> <x> <y> [原因]` | 只能是「单位」页里定义过的单位 |
| 改变地形 | `terrain <x> <y> <地形名> [原因]` | 只能是定义过的地形 |
| 结束战斗 | `end <victory\|defeat> [原因]` | 默认不允许 |

- 单位可以写编号（P1、E2）、名字或别名；指令也接受中文（伤害、治疗、状态、移动、撤退、增援、地形……）。
- **确认模式**（默认）：提议会列在战场页上方，逐条显示预演结果，无效的会标出原因；勾选后点「应用」。**自动模式**：同步完就应用，无效的指令会提示。
- 应用后的变化记入战斗记录（`【剧情】…`），不会再作为“需要描写的行动”发给聊天 AI，因为剧情里已经写过了。
- **重新生成 / 滑动 / 删除**同步读到的最后一楼时，它造成的改动会自动撤回；如果之后棋盘又有别的改动，就不会自动撤回，只会提示（可以用「撤销」）。
- 每类指令都可以单独关闭，HP 变化上限、能否直接击败也可以调整。

## 任务

| 任务 | 胜利 | 失败 | 敌人 AI（主动出击） |
| --- | --- | --- | --- |
| 歼灭战 | 击败所有敌人，且不再有后续增援 | 我方全灭；或超过回合限制 | 按距离从近到远，攻击最近的能打到的角色；打不到就向最近的角色前进 |
| 守城战 | 坚守到指定回合结束；或击退所有敌人（含增援） | 被摧毁的我方/友军「★ 关键目标」达到设定数量（默认 1 个，可设为全部）；或我方全灭 | 无视角色，朝守卫目标前进并攻击它；被挡住时攻击挡路的角色 |
| 进攻战 | 摧毁所有敌方「★ 关键目标」（敌人不必全灭） | 我方全灭；或超过回合限制 | 同歼灭战，守在目标附近的敌人建议设为「原地迎击」或「固守不动」 |

- **关键目标**：在单位页勾选「★ 关键目标」。它可以是角色（例如要保护的王子、要击杀的首领），也可以是**建筑 / 目标物**（类型选「建筑 / 目标物」，只有 HP / DEF / MDEF，不会行动、不会反击，例如城门、魔法水晶、旗帜）。
- **增援**：每个增援波次设置单位、出现位置、每次数量、首次出现回合、间隔回合（0＝只出现一次）、最多次数（0＝无限）。增援在该回合敌方/友军阶段结束时出现，下一回合才会行动；出现点被占据时会在附近 3 格内找空位。棋盘上红色虚线 ⚑ 是增援出现点，本回合结束就会出现的会闪烁。增援点也可以用于友军（单位阵营决定增援属于哪一方）。
- 守城战可以放置多个关键目标（如城门加几名平民），在任务设置里填写「被摧毁几个算失败」：默认 1，任意一个被摧毁即失败；填 2 就允许损失 1 个；大于等于关键目标数量时，全部被摧毁才失败。任务说明和 LLM 读取的战场信息会显示已摧毁数量。已经开始的战斗沿用开战时的设置。
- 开战前会检查任务设置：守城战必须有我方关键目标，进攻战必须有敌方关键目标，歼灭战不能有无限次的敌方增援。
- 当前任务、剩余回合和增援预告会写进注入的战场状态，任务开始时还会作为第一条行动发给 LLM。
- 自带四张示例地图：「河畔之战」（歼灭）、「死守城门」（守城，5 回合，每 2 回合 2 只哥布林增援）、「破坏水晶」（进攻，第 2、5 回合增援）、「夜袭森林」（歼灭，战争迷雾）。已经安装过的用户，示例资料卡不会自动更新；可以在资料卡页点「示例」新建一张示例资料卡获取新地图。

## 技能与效果

**技能类型**

| 类型 | 作用对象 | 说明 |
| --- | --- | --- |
| 物理伤害 | 敌方 | `ATK × 威力%` 对 DEF 计算伤害，可附加效果（命中且未被击败的目标获得） |
| 魔法伤害 | 敌方 | `MATK × 威力%` 对 MDEF 计算伤害，可附加效果 |
| 辅助 | 友方（含自己）/ 敌方 / 仅自己 / 空地（传送自身） | 不造成伤害，只施加效果；「仅自己」的技能点击后立即释放；「空地」为传送技能 |

每个技能可以设置：射程、范围半径、命中修正（±%）、必中、**冷却回合**（N＝每 N 回合可用一次，0 或 1＝每回合可用）、每场战斗的使用次数（0＝无限）。冷却在使用者阵营的阶段开始时减少，冷却中的技能按钮会显示「第几回合可用」。

- **速攻**（辅助技能可勾选）：选中角色后随时可用，移动前后都可以，不消耗行动和攻击机会；每个速攻技能每回合最多使用一次（冷却至少按 1 回合计）。按钮前带 ⚡，用完后角色仍保持选中，可以继续移动或行动。敌方 / 友军 AI 会在行动前先使用有价值的速攻技能。
- **传送**（辅助技能的作用对象选「空地（传送自身）」）：点击射程内的空地，施法者瞬间移动过去，无视路径、敌人阻挡和移动消耗；不能落在有单位或无法站立的格子上，落脚地形伤害照常。技能效果作用于施法者自己（可以不加效果）。可以与速攻组合成「闪现」。
- **援护**：被援护的攻击按援护者计算命中、伤害和地形，由援护者选择「防御」或「承受」（消耗援护者的韧性），援护者不反击。MAP 攻击和范围技能不会被援护。眩晕或倒下的援护者无法援护；同时有单体援护和范围援护时，单体援护优先，多个范围援护时由离目标最近的承受。战斗确认会提示「某某将替某某承受这次攻击」，描写中写作「挺身援护」。AI 会在同伴受威胁时使用援护和范围援护。
- 例：坦克的「援护」＝作用对象「友方」＋效果「援护」（持续 1 回合，覆盖接下来的敌方阶段）；升级版「守护领域」＝作用对象「仅自己」＋效果「范围援护 2 格」。
- 例：盗贼的「快速行动」＝作用对象「仅自己」＋勾选「速攻」＋效果「额外行动」。每回合先点 ⚡快速行动，然后移动、攻击，再移动、攻击；单位卡片会显示「额外行动 ×1」。内置 AI 不使用传送，LLM 指挥官同样不会得到传送选项。

**预设效果**：效果类型是固定的预设，不能新建；编辑技能时只能从下面选择，再调整数值和持续回合。

| 分组 | 效果 | 可调数值 | 说明 |
| --- | --- | --- | --- |
| 立即 | 恢复HP | MATK 的百分比 | 立即恢复 `施法者MATK × 数值%` |
| 立即 | 恢复HP（按比例） | 最大 HP 的百分比 | 立即恢复 `目标最大HP × 数值%` |
| 立即 | 驱散减益 | — | 移除目标身上所有减益 |
| 立即 | 额外行动 | — | 本回合多行动一次：已经行动过的同阵营目标立即可以再行动；尚未行动的目标（包括施法者自己）在下一次行动结束后可以再行动，并且能重新移动。只对正在行动的阵营有效，每个单位每回合最多获得一次，没用掉的回合结束失效。AI 会用它让同伴或自己多打一次 |
| 立即 | 召回到身边 | — | 目标瞬间移动到施法者身边离它最近的空格，可用来救援平民；建筑不受影响，落脚地形伤害照常。内置 AI 不主动使用 |
| 增益 | 攻击力 / 魔攻 / 防御力 / 魔防上升 | 百分比 | 属性按百分比提高 |
| 增益 | 敏捷上升 | 百分比 | 提高命中与闪避 |
| 增益 | 移动力上升 | 格数 | 移动力增加固定值 |
| 增益 | 视野上升 | 格数 | 战争迷雾中视野增加固定值 |
| 增益 | 持续恢复 | 最大 HP 的百分比 | 自己阵营的阶段开始时恢复 |
| 增益 | 嘲讽 | 影响范围（0＝全图） | 范围内的敌人只能攻击带嘲讽的单位，AI 会朝它前进；我方被敌人嘲讽时同样只能攻击嘲讽者 |
| 增益 | 援护 | — | 施法者替目标承受下一次单体攻击（普通攻击或单体伤害技能），承受一次后消失。不能援护自己 |
| 增益 | 范围援护 | 范围（格） | 获得者周围此范围内的友军（包括城门等建筑）受到单体攻击时，都由获得者承受，持续期间不限次数 |
| 减益 | 攻击力 / 魔攻 / 防御力 / 魔防下降 | 百分比 | 属性按百分比降低 |
| 减益 | 敏捷下降 | 百分比 | 降低命中与闪避 |
| 减益 | 移动力下降 | 格数 | 移动力减少固定值 |
| 减益 | 视野下降 | 格数 | 战争迷雾中视野减少固定值 |
| 减益 | 暴露行踪 | — | 战争迷雾中，所有敌人都能看到该单位 |
| 减益 | 中毒 | 最大 HP 的百分比 | 自己阵营的阶段开始时损失生命，最多降到 1，不会因中毒倒下 |
| 减益 | 眩晕 | — | 无法行动 |

- 持续效果的回合数在**施法者阵营**的阶段开始时减 1，归零即结束。所以给同伴加持续 1 回合的防御，会覆盖接下来的整个敌方阶段；敌人给你上的减益，也会持续到你自己的下一个阶段。
- 同一种效果再次施加时会刷新为新的数值和回合数，不会叠加。
- 单位卡片里，受影响的属性会变成绿色或红色，下方列出状态和剩余回合；棋子左上角有状态标记。注入给 LLM 的战场状态里也会写明每个单位身上的效果。
- AI 会比较「攻击」和「辅助技能」的价值：同伴 HP 低于 70% 时治疗，敌人逼近时给同伴加增益或自己嘲讽，也会给敌人上减益。估值时按命中率折算期望伤害，所以 AI 会优先打容易命中的目标，不会去打命中率 0% 的目标。
- 旧版的「治疗」技能会自动转换成「辅助·友方 + 恢复HP」，原来的威力变成恢复数值。

## 规则

| 项目 | 计算 |
| --- | --- |
| 物理伤害 | 减法：`ATK×威力% − DEF`；比例：`a²/(a+DEF)`，a = ATK×威力% |
| 魔法伤害 | 同上，改用 MATK / MDEF |
| 命中率 | `基础命中 + (攻方AGI − 守方AGI) × 系数 + 技能命中修正 − 守方地形闪避`，限制在 0–100%。默认基础 90%、系数 3% |
| 命中判定 | 普通攻击、反击、伤害技能、对敌方的辅助技能（减益）会判定；范围技能对每个目标分别判定。对友方的技能、攻击建筑物、「必中」技能一定命中。设置里可以关闭命中判定 |
| 地形减伤 | 伤害 × (1 − 防守方所在地形的减伤%) |
| 浮动 | 伤害 × (1 ± 浮动%)，四舍五入，至少为「最低伤害」 |
| 增益 / 减益 | 先按百分比修正，再加减固定值，四舍五入，最低为 0 |
| 反击 | 只有普通攻击会触发；防守方存活且攻击者在其射程内时反击 |
| 移动 | 消耗 = 地形移动消耗，可以是小数（0.5＝在该地形上移动距离翻倍）；不能穿过敌人；可以穿过友方但不能停在友方格子上；飞行单位每格消耗 1，只受「飞行可通过」限制 |
| 回合 | 我方 → 敌方（AI）→ 友军（AI）→ 下一回合。阶段开始时，站在回复地形上的单位会恢复 HP |
| 胜负 | 见上方「任务」 |

AI 行为（每个敌方 / 友军单位单独设置）：

- **主动出击**：按任务寻找目标（见上表；被嘲讽时只找嘲讽者），绕开障碍前进；与辅助技能比较后选择价值更高的行动
- **原地迎击**：只攻击本回合移动后能打到的目标，打不到就不动
- **固守不动**：不移动，只攻击射程内的目标
- **远程游击**：适合弓手、法师等远程单位。能攻击时，从敌人下回合最难打到的格子出手；打不到目标时朝目标前进，但停在敌人的攻击范围边缘，不主动踏入；已在危险中又无法攻击时会后撤
- **逃跑**：适合平民、商队等需要保护的目标。敌人下回合打不到它时原地不动；进入敌人的威胁范围后，逃到威胁最小、离敌人最远的格子，并避开熔岩等伤害地形。不会攻击，但可以使用治疗等辅助技能

威胁范围按敌人当前位置估算：移动力加普通攻击射程和伤害技能范围（含MAP直线 / 范围），眩晕的敌人和建筑不计。LLM 指挥官也会得到「逃离敌人」「保持距离前进」的选项。

**鲁莽使用MAP攻击**（有MAP技能的敌方 / 友军单位，默认开启）：只要MAP攻击能打到敌人就会发射，不顾误伤友军，所以可以把它引到自己人的队列上（例如用挑衅站进敌群所在的直线）一次清掉大量敌人。关闭后，误伤友军的损失大于收益时不会使用。修改后对已在场的单位立即生效；MAP作用对象设为「仅敌方」的技能不会误伤。

## 设置项

- **描写模式**：分别开关移动、普通攻击、技能、敌人行动、友军行动、回合切换、增援出现、状态变化（中毒 / 持续恢复 / 眩晕 / 效果结束）。关闭的项目可以作为「背景信息」一句话带过，也可以完全省略。
- **发送方式**：弹出预览（可编辑）/ 直接发送 / 只填入输入框；结束回合后是否自动整理；可自定义消息开头的指令。
- **战斗规则**：伤害公式、浮动、最低伤害、反击开关、韧性系统（所有单位 / 仅我方角色 / 关闭）。
- **LLM 读取战场**：自动注入（位置、深度、身份、包含的部分）、宏、函数调用工具，详见上方「LLM 读取战场」。注入内容允许世界书扫描，所以写在战场信息里的单位名和别名也能触发世界书条目。
- **界面**：完整窗口 / 战斗小窗、格子大小上限（棋盘按面板的宽度和高度自动缩放，默认最大 48 像素）、是否显示悬浮按钮、行动过程动画与速度。界面颜色跟随 SillyTavern 主题（浅色、深色主题都适用）。
- **导入 / 导出**：导出全部资料卡和全局设置；导入时可以选择覆盖同 ID 的资料卡或作为副本导入，也能读取旧版本的导出文件。「恢复默认设置」只重置全局设置，不影响资料卡。

## 已知限制

- 战斗状态不会随 swipe / 重新生成 / 删除消息回滚。需要回退时，请在发送前使用「撤销」。
- 战斗开始时会复制一份单位数值和地形，战斗中修改定义不影响正在进行的战斗（世界书绑定除外，它会同步过去）。
- 地图最大 40×40。

## 单位特质

在「单位 → 特质」中选择已有特质或创建新特质，然后填写名称、描述并添加多个效果。例如「强壮」配置 ATK +10%，「再生」配置每次自己阵营回合开始恢复最大HP的10%，「欠揍」配置3格内敌人优先攻击自己。一个特质可以同时包含这三种效果，一个单位也可以拥有多个特质。

特质不消耗行动、不会过期、不能被驱散；与技能施加的临时状态叠加。百分比属性修正相加后作用于基础数值，再加固定修正，最终取整；回复HP不会超过上限，也不会复活。恢复在地形伤害和地形回复之后、临时状态结算之前发生。吸引范围使用曼哈顿距离，以敌人阵营阶段开始的位置判断；0代表全图。它影响AI的目标优先级，不限制玩家选择攻击对象，无法攻击吸引者时可以攻击其他目标；技能嘲讽的强制规则仍优先。LLM指挥官也会获得优先目标提示。

描述会与实际效果一起提供给LLM用于描写；描述本身不执行规则，请用效果组合配置数值行为。特质随资料卡保存、导出和分享，进入战斗或新摆放/增援时复制到单位；编辑资料卡不改变已经在场的单位。旧资料卡和已有战斗无需迁移，默认为没有特质。

## 受击描写与暂停

敌方攻击我方角色时，可以直接选择反击 / 防御，或选择「反击并生成描写 / 防御并生成描写」。无法反击时仍提供「防御并生成描写」。本回合结算完成后，会将选择生成的交战合并发送一次给LLM并要求详细描写；自上次发送以来的其他行动（包括本回合其余交战）作为「背景信息」附在同一条消息里，然后清空待发送列表，下次发送只包含之后发生的行动，不会重复要求描写已经过去的部分。如果LLM正在生成，生成描写按钮会提示等待，仍可选择普通反击或防御。取消本次回合不会发送描写。

完整窗口与小窗顶部都有「暂停战斗」。暂停保留当前战斗进度，并显示只读地图和「继续战斗」；暂停期间可以正常聊天，插件不提供战场提示词、不同步战场变化。与关闭窗口不同，暂停状态也会随聊天保存；关闭、刷新或切换聊天后返回仍可继续。正在播放过程、结算回合或等待受击选择时，需先完成结算再暂停。

## 战斗回溯

开战和每个我方阶段开始时，插件会自动保存一份战场存档，随聊天保存，最多 20 份（始终保留开战存档）。点击「回溯」（小窗在「战斗管理」中）可以看到各存档的回合、当时的聊天楼层、双方存活人数和时间，选择「回到这里」后，棋盘、HP、技能冷却、状态与增援进度都恢复到那时。

回溯不会删除或修改聊天记录，可以直接在聊天里补录对话，然后继续战斗。待发送行动中会加入一条「战斗回溯」说明，下次发送时告诉 LLM 战场已经回到哪个回合。回溯前的当前进度会自动保存为「回溯前的进度」（包括当时未发送的行动），之后可以再回去；也可以用「撤销」立即撤回这次回溯。更新前已经开始的战斗从下一回合开始记录存档。
