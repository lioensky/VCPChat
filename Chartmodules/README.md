# VChat 图表系统

VChat 图表系统通过内置的 **ChartController 插件**，让 Agent 帮你生成、管理和展示图表。你只需要描述想看什么、数据来自哪里，Agent 就可以调用插件创建图表，并在图表工作台中打开。

它不只是一次性的图表输出，更适合持续更新的数据看板、统计报表和监控面板。

## 核心优势：图表生成一次，后续只更新数据

图表的展示代码与数据分开管理：

- **首次创建**：Agent 生成图表的结构、样式和渲染逻辑，并提供初始数据。
- **数据变化**：可以替换整份图表数据，也可以仅对发生变化的部分进行增量更新。
- **展示复用**：已有图表接收数据更新，无需每次重新输出完整 HTML 代码。
- **需要改版时**：再修改图表的布局、样式或交互逻辑。

例如，新增一天的销售记录、修正某个统计值、追加一批采样数据，通常只需更新表数据，不必重新生成整个页面。这能减少重复输出，让 Agent 维护长期使用的图表更方便。

> 图表的渲染逻辑需要支持相应的数据更新方式；数据与展示分离并不意味着所有自定义图表都能自动适配任意数据结构。

## 使用本地或网络数据

除了让 Agent 直接提供数据，图表运行时还提供数据源读取能力，包括：

- 本地 JSON、文本和 CSV 数据；
- 本地 SQLite 数据库的只读查询；
- 网络 JSON 接口。

数据源读取由 VChat 的图表数据源服务处理，实际可用范围以服务的访问校验和运行环境为准。

你可以让 Agent 读取数据后更新图表，也可以让 Agent 为图表编写按需读取或定时刷新的逻辑。**接入数据源不等于自动监听所有变化**：需要根据实际需求配置刷新逻辑，或由 Agent 在数据变化时调用插件更新。

## 如何使用

确保当前 Agent 可以调用 VChat 内置的 ChartController 插件，然后直接用自然语言提出需求，例如：

> 帮我创建一个销售趋势图，读取指定的本地 CSV 数据，并打开图表工作台展示。

> 使用这个网络 JSON 接口创建一个监控面板，每分钟刷新一次，复用已有图表。

> 给刚才的图表追加今天的数据，只更新数据，不要重新生成完整 HTML。

> 将现有图表改成按月份汇总，保留原来的配色。

Agent 通过插件完成图表的创建、查询、修改、数据更新和展示管理；具体可用操作以当前 ChartController 的工具说明为准。

## 工作台与桌面悬浮窗

- **图表工作台**：集中浏览和搜索图表，选择后即可展示；支持重新加载、在 Canvas 中编辑和删除。
- **悬浮展示**：点击工具栏“悬浮展示”，或使用图表列表的右键菜单，将图表独立放到桌面。
- **多个图表并行展示**：不同图表可各自打开悬浮窗，支持拖动、缩放和置顶切换。
- **避免重复渲染**：图表分离后，工作台显示“独立展示中”，并释放原来的图表运行实例。
- **随时收回**：通过“收回工作台”或悬浮窗中的“回到工作台”恢复集中展示。

无论在工作台还是悬浮窗中，图表都可以继续接收数据更新。对于需要长期观察的数据，创建好图表后持续维护数据即可，不必反复生成整页展示代码。

## 在聊天消息中引用图表

Agent 创建图表后，可以在主聊天消息正文中输出下面的专用围栏，直接展示已有图表，不必再次输出图表源码：

````text
```vcp-chart
id: cpu-monitor
height: 360
title: CPU 实时监控
```
````

- `id` 必填，使用 ChartController 返回的图表 ID（2～64 位小写字母、数字、短横线或下划线）。
- `height` 可选，默认 360，允许 180～900，单位为像素；包含标题栏。建议根据图表布局选择高度。
- `title` 可选，默认显示图表 ID。
- 引用必须为独立、完整闭合的围栏。工具请求、工具结果、思维链和其他代码示例中的内容不会作为普通正文引用自动播放。
- 流式生成期间仅展示占位框，消息完成后才参与自动播放。

### 同 ID 单实例与固定占位

同一聊天渲染器内，相同图表 ID 的引用共享一个隔离运行实例，默认在最后一个已完成的引用中展示。其他引用保留相同高度的占位框，点击“播放”可把运行实例转移到该处，不重新初始化图表。占位框提供“工作台”和“复制引用”入口。

播放、转移、暂存不会改变框体高度。消息重新渲染时，运行实例会先移入常驻停靠区，再移回新的占位框；切换话题、清空聊天或销毁渲染器会释放实例。每个渲染器默认最多保留 4 个实例，超出限制时优先释放离屏实例；没有可释放实例时可以打开工作台查看。

引用始终读取图表的当前版本，不是发消息时的历史快照。数据变更会同步到运行实例；源码变更会重新挂载。图表被删除或读取失败时显示状态提示。消息中的实例与工作台、悬浮窗各自独立；单实例约束仅适用于同一个聊天渲染器。

### 图表运行时建议

消息图表在不具备同源权限的 iframe 沙箱中运行，不能访问聊天窗口 DOM、Electron API 或任意本地脚本。依赖库仅允许系统白名单中的本地 anime、three、pixi，数据源通过只读桥调用。

离屏时暂停通过 `context.resources` 登记的回调和受管理动画；重新可见时恢复，不重建图表。自定义渲染循环应使用 `context.resources.requestAnimationFrame` / `setInterval`，必要时实现可选的 `pause(context)` 与 `resume(context)` 钩子。绕过资源管理器直接创建的原生计时器、Three.js 自有循环等不能保证被通用暂停协议自动停止。

当前客户端要求支持保留状态原子移动的 Electron 运行时；不支持时保留静态引用，并可通过“工作台”查看。本功能不包含 Excel 导入或公式计算。
