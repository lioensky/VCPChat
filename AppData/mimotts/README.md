# MiMo TTS 克隆参考音频

将用于 MiMo 2.5 TTS 音色克隆的参考音频放在此目录中。

## 使用方法

1. 将参考音频复制到本目录。
2. 打开 VCPChat 的 Agent 设置。
3. 确认全局语音工作模式为“网络 MiMo TTS 模式”。
4. 在 Agent 的“语音设置”中点击刷新按钮。
5. 从“MiMo 克隆音色（AppData/mimotts）”分组选择对应文件名并保存。

## 支持格式

- WAV
- MP3 / MPEG
- M4A
- AAC
- FLAC
- OGG / OGA
- WebM

实际可用格式仍取决于当前 MiMo API 服务或兼容网关的能力。优先推荐 WAV 或 MP3。

## 自然语言演绎控制

克隆模式支持 Agent 的“MiMo 自然语言演绎提示词”。参考音频会作为 voice 发送，提示词会合并为一条 user 消息，用于微调语速、情绪、气息、停顿和发音风格；待朗读文本作为 assistant 消息发送。

克隆模型按官方协议仍使用 stream=true。当前服务可能在所有推理完成后，以 SSE 格式一次性返回完整音频；VCPChat 会兼容这种降级行为，并继续按句处理朗读队列。

## 内存与版本控制

- VCPChat 仅在实际推理时读取选中的参考音频。
- 进程内最多常驻 2 个参考音频，采用最近最少使用替换策略。
- 替换同名文件后，程序会根据文件大小和修改时间自动重新加载。
- 关闭 VCPChat 后，内存中的参考音频会自然释放。
- 本目录由 Git 完整追踪，以便随项目分发官方默认 Agent 的参考音频。
- 请勿将私人录音或未经授权的声纹素材放入本目录后提交。
