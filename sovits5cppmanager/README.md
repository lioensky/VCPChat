# sovits5cppmanager

GPT-SoVITS V5 / gsv.cpp 参考声音管理器。无需训练，但必须提供参考音频及其准确文字。

- GitHub：https://github.com/KakaruHayate/gsv.cpp
- Windows 一键包：https://huggingface.co/KakaruHayate/GSV.CPP/tree/main/windows
- 官方补丁与发布说明：https://github.com/KakaruHayate/gsv.cpp/releases

## Windows 一键包：安装后必须检查并应用官方补丁

**Windows 一键包可能落后于官方修复版本，不能把解压一键包当作升级完成。** 截至 2026-11-07，基础一键包为 0.1.0；应按官方发布说明应用最新适用的累积 patch。当日验证：应用官方重发版 **v0.1.2** 累积补丁后，下述合成异常恢复正常。以后请以官方最新发布说明为准，不要仅凭安装目录名称判断引擎版本。

旧版已知问题：首次合成正常，但再次准备参考音频（例如切换音色、同一音频换路径或重新上传）后，可能出现语无伦次、拖音及生成时长暴涨。根因是 HuBERT 注意力 mask 所在可复用内存被覆盖；固定路径命中参考缓存时可能暂时隐藏问题。**这不是中英混合 `zh` 或语速设置导致的，不能靠提高语速解决。**

升级步骤：
1. 从官方 Releases 下载适用于一键包的最新累积补丁；本次验证使用的是重发版 `GSV.CPP-win64-patch-0.1.2.zip`，不是早期已撤回的 0.1.2。
2. 完全关闭 GAG 及其 API / 文本侧车进程，备份即将覆盖的文件与配置。
3. 按官方说明，将补丁完整解压覆盖到一键包根目录。**EXE 与配套 ggml DLL 必须成套更新，不要只替换 EXE，也不要混用旧 DLL。** 累积补丁无需重新下载模型；保留参考音频、用户预设与配置（该版官方说明不会覆盖 `GAG_config.json`）。
4. 重启服务，并连续合成、切换参考音频复验；仅测试冷启动后的第一条语音不足以验证修复。已经缓存到 VChat 的异常语音不会因引擎升级自动重生成，复验时使用新文本或清理对应语音缓存。

只执行 `git pull` 不会更新一键包里的预编译引擎；源码安装需要另外重新构建并部署运行文件。

## 启动
环境：Node.js 22+。无需额外 npm 安装。

在 VChat 根目录运行：
```powershell
node sovits5cppmanager/server.js
```
浏览器打开 http://127.0.0.1:9885 。用 Ctrl+C 关闭。可通过 GSV_MANAGER_PORT 修改端口。

1. 下载一键包，在纯英文路径解压，**先按上文应用官方最新适用的累积 patch 补丁**，再启动其中的 API 服务，默认 http://127.0.0.1:9880。
2. 管理页新建预设，上传 3–10 秒标准 PCM WAV，填写准确参考文字、参考语言及目标语言。
3. 填写暴露模型名；引擎 voice 默认为 `default`，与暴露名称不是一回事。
4. 保存后可试听。Turbo 通常使用 4 步，Dev 通常使用 32 步，以加载模型实际能力为准。
5. VChat 全局设置选择本地推理模式，填写 GSV URL；Agent 设置刷新音色列表并选择预设。
6. 旧 SoVITS 模型 ID 不自动映射，必须重新选择。网络 MiMo 模式不变。

## 数据
数据位于当前安装根目录 `AppData/sovits5cpp`：
- `presets.json`：版本化声音列表。
- `refs/<sha256>.wav`：托管音频，不依赖原始文件位置。

```json
{
  "version": 1,
  "presets": [
    {
      "id": "kerr-default",
      "name": "Kerr · 默认",
      "audio": "<导入后生成的64位sha256>.wav",
      "promptText": "参考音频实际说出的文字",
      "emotion": "默认",
      "promptLang": "all_zh",
      "textLang": "auto",
      "speed": 1,
      "engineVoice": "default",
      "sampleSteps": 4
    }
  ]
}
```
示例 audio 为占位符，不能直接使用。建议经管理页导入保存；备份时复制整个目录。
ID 为稳定 ASCII 标识，主程序使用 `gsv:<id>`；修改名称不破坏 Agent 选择。
情绪是描述参考音频的元数据，不向引擎发送虚构的情绪参数。
实际合成语速 = 预设语速 × Agent 语速，必须在 0.1–3 内。
参考语言与目标语言独立。`all_zh` 是中文、`zh` 是中英混合；其他语言类似。
管理器删除预设不会删除音频，防止误伤共用素材；未使用素材可在完整备份后手动清理。
保存使用串行队列与临时文件原子替换；同一安装仅运行一个管理器，不与外部编辑器同时写 JSON。

## 中文路径限制
引擎不能处理中文路径。中文 UI 名称、参考文字、原始文件名可以使用；导入后改用哈希文件名。
合成前通过 `/reference` 上传，避免白名单目录耦合。
**引擎自身及 TEMP/TMP 的完整绝对路径也必须是 ASCII。**
若 `/reference` 返回中文路径，管理器明确拒绝；请在启动引擎前为其设置英文 TEMP/TMP 目录后重启。
管理器不会修改系统环境变量或用户引擎配置。

## 范围与安全
只监听 127.0.0.1，管理写请求有同源与专用请求头校验。不要反向代理到公网。
第一版仅接受 PCM WAV，不自动安装转码工具；其他格式先自行转换。
管理器不启动、下载或停止引擎。试听仅支持本机无鉴权服务；主程序沿用全局 URL/Key。
预设列表在引擎离线时也可读取，合成和试听需要引擎在线。
缓存身份包含完整预设和参考内容哈希。修改音频、台词、语言、语速或引擎 voice 后不会复用旧缓存。
目前停止朗读使播放会话失效，不代表 C++ 引擎端计算被取消。
`<<开心>>` / `<<开心|日语>>` 文本标签解析属于后续阶段，当前不实现。
