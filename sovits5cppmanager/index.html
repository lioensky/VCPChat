路径与使用约定

引擎安装路径以及 TEMP/TMP 必须全英文。导入音频会按内容哈希重命名，中文原文件名无需手动修改。引擎返回中文临时路径时会明确报错。

管理器不负责下载、启动或关闭 GSV 引擎。先启动一键包中的 API 服务，再试听。第一阶段不解析 <<开心>> 等正文标签；请为不同参考音频创建独立预设。
