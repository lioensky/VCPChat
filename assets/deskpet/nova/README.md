# 内置 Nova

两套 Nova 形象通过桌宠「换装」选择，ID 分别为 `builtin:nova-maid`、`builtin:nova-chibi`。新建 Nova 默认用女仆。科技服已从内置资源移除；另附的 Codex 精灵刻晴、乐奈在 `../codex/`。仅从应用目录读取。用户模型继续放在自己的 `Agents/<id>/deskpet/`，选择记录仍由现有 `deskpet/state.json` 管理。

每套包含 Cubism `.moc3`、`model3.json`、贴图、物理配置和动作。女仆有十二套独立参数表情，对应系统十二个情绪；Q 版的十一套表情和手势见下文。口型、呼吸、视线和互动使用现有桌宠运行时。Q 版另附十二情绪和状态立绘，作为无 Core 时的回退。

美术来自本次 Nova 制作：修正颈部阴影的女仆全身、清理刘海和眼周残影的简洁 Q 版。源图、拆层 PSD 和动作差分由独立美术包保存，运行资源不包含编辑器工程。初版使用 PSD2Live 自动绑定，适合功能验证；后续可在 Cubism 编辑器里细化闭眼形状、嘴型与肢体动作。

本目录不含 `live2dcubismcore.min.js`。运行时沿用应用数据目录中已配置的 Core 5.x；缺少运行库或显卡不可用时回退到本套立绘。不要把第三方 Core 或示例模型混入本目录。

2026-10-11：通过原生 PSD2Live 工程重新导出女仆与 Q 版，清理头发、睫毛、脸部、脖子和口型的残留。最终替换素材、编辑操作和校验记录见 `scripts/deskpet/materials/nova-native-20261011/`，替代旧版贴图补丁。按用户要求，Q 版腿、袜子、鞋恢复原版素材与网格，保留头发和表情修复。女仆脸部与睫毛已重新按原图注册对齐，去除脸皮里重复的鼻尖，仅使用独立鼻子；撤回之前睫毛下移补偿。

## Q 版（chibi）第二版

Q 版已改为模型自带的表情与手势，不再只是立绘差分：

- 表情 11 套（`expressions/`）：Neutral、Happy、Shy、Sad、Angry、Surprised、Tired，新增 Stars（星星眼）、Wink、Smug、Speechless。`deskpet.json` 的 `expressions` 把十二个情绪全部映射到这些表情（calm 与 neutral 共用 Neutral，睡眠走 tired → Tired）。
- 手势 8 个（新增 motion3）：Wave、Salute、Heart、Tea、Typing、Shrug、Akimbo、Cheer，加上原有的 Nod、Shake。`deskpet.json` 的 `motions` 和生活动作（摸头、打哈欠、伸懒腰、哼歌、醒来、落地等）都映射到这些动作。
- 闭眼：EyeOpen 降到 0.3 以下时，眼线保持弯成眼皮的形状，眼白（带青色虹膜）在 0.45→0.3 之间淡出；每一套表情的眼睛都这样处理（Stars 没有眼线，闭眼时借用中性眼皮），所以任何表情下眨眼、闭眼和睡觉都只剩深色眼皮弧线，不露青色。
- 口型：表情自带的嘴没有张开状态。MouthOpenY 在 0.05 到 0.1 之间，表情嘴淡出、中性说话嘴淡入（0.1 时完全切换），所以任何表情下说话都会动嘴；表情的 MouthForm 仍然作用在说话嘴上。
- 绘制顺序：前发在 AngleX 每个关键帧（含 0）都画在脸和眼睛之上，转头时眉形碎片不会透出来。
- 后发和头饰清理已回写原生工程；导出后不要再运行旧版贴图后处理。中性眼线、闭嘴线和困倦眼皮保留原有清晰线条。

已知未修：眼珠移动幅度很小（D9）、身体转角幅度小（D10）、腿鞋沿用原版，包括原有接缝（D11）、歪头 ±4° 时内侧头发偶尔有一条很淡的细线（D12 残留）、手势开始和结束时手臂是瞬间切换的（交叉淡化会出现两双手臂，所以保留瞬切）。

女仆轮廓复核：新脸皮的下巴相对原画偏左、偏上，已通过下半脸网格补偿修正；眼睛、鼻子、眉毛和嘴巴网格保持原位。不能将“网格与原版一致”视为换素材后视觉位置正确的证明。
